# 1️⃣ Ruby 객체 & 클래스 개념 (Vagrantfile에 필요한 만큼만)

## 1-1️⃣ Ruby는 전부 객체다

Ruby의 가장 중요한 특징:

> **모든 것은 객체(Object)**

`"abc".length 10.to_s :virtualbox.to_s`

👉 숫자, 문자열, 심볼, 설정 객체까지 전부 객체

---

## 1-2️⃣ 객체 = 상태 + 행동

`vb.cpus = 2`

- `vb` → 객체
    
- `cpus=` → 메서드
    
- `2` → 인자
    

✔ **속성처럼 보이지만 메서드 호출**

---

## 1-3️⃣ setter / getter 개념

`vb.memory = 2048`

실제 내부 호출:

`vb.memory=(2048)`

반대로 읽을 때:

`vb.memory`

✔ Java의 `setMemory()`, `getMemory()` 와 동일  
✔ Ruby는 문법을 짧게 만든 것뿐

---

## 1-4️⃣ Vagrant 객체 관계 (중요)

`config  └─ vm     ├─ define     ├─ network     ├─ synced_folder     └─ provider          └─ vb (VirtualBox 전용 객체)`

👉 `config`, `cfg`, `vb`는 **전부 Vagrant가 만들어 준 객체**
