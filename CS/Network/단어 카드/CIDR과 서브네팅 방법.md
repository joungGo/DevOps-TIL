# 1️⃣ CIDR와 서브네팅 계산 방법

## 1. CIDR(Classless Inter-Domain Routing)

CIDR은 **클래스(A/B/C)를 무시하고 프리픽스 길이(/n)** 로 네트워크 범위를 표현하는 방식이다.

형식:

```
IP주소/프리픽스길이
예) 192.168.1.0/24
```

의미:

- `/24` → 앞의 24비트가 네트워크 ID
    
- 나머지 비트가 호스트 ID
    

---

## 2. 서브넷 마스크 계산

### 프리픽스 → 서브넷 마스크

|프리픽스|서브넷 마스크|
|---|---|
|/8|255.0.0.0|
|/16|255.255.0.0|
|/24|255.255.255.0|
|/26|255.255.255.192|
|/27|255.255.255.224|
|/28|255.255.255.240|

---

### 호스트 수 계산 공식

```
호스트 수 = 2^(32 - 프리픽스) - 2
```

- `-2` 이유:
    
    - 네트워크 주소
        
    - 브로드캐스트 주소
        

예:

```
/26 → 32 - 26 = 6
2^6 - 2 = 62개
```

---

## 3. 서브네팅 계산 절차 (핵심)

### 예제

```
192.168.1.0/26
```

1. 프리픽스: `/26`
    
2. 호스트 비트: 6비트
    
3. 블록 크기:
    

```
2^6 = 64
```

4. 네트워크 증가 단위:
    

```
0, 64, 128, 192
```

# 2️⃣ IP 주소 설계 예제

## 요구사항

- 하나의 네트워크
    
- 최소 50대 호스트 필요
    

---

### 1단계: 필요한 호스트 수 계산

|프리픽스|호스트 수|
|---|---|
|/27|30 (부족)|
|/26|62 (충분)|

→ `/26` 선택

---

### 2단계: 네트워크 설계

```
네트워크 주소: 192.168.10.0/26
```

- 서브넷 마스크: 255.255.255.192
    [[CIDR을 서브넷 마스트로 변경하는 방법]]
- 블록 크기: 64
    - 10진수로 `0~63` -> 첫 번째 서브넷은 `192.168.10.0  ~ 192.168.10.63`

---

### 3단계: 주소 범위 정리

|구분|주소|
|---|---|
|네트워크 주소|192.168.10.0|
|사용 가능 IP|192.168.10.1 ~ 192.168.10.62|
|브로드캐스트|192.168.10.63|

서브넷 내 주소 역할

| 구분       | 이유            |
| -------- | ------------- |
| 네트워크 주소  | 호스트 비트 = 전부 0 |
| 브로드캐스트   | 호스트 비트 = 전부 1 |
| 사용 가능 IP | 그 사이          |

---

## 여러 서브넷으로 나누는 예제

```
192.168.1.0/24 → /26으로 분할
```

|서브넷|네트워크|호스트 범위|브로드캐스트|
|---|---|---|---|
|1|192.168.1.0|.1 ~ .62|.63|
|2|192.168.1.64|.65 ~ .126|.127|
|3|192.168.1.128|.129 ~ .190|.191|
|4|192.168.1.192|.193 ~ .254|.255|

# 3️⃣ 네트워크 주소 / 브로드캐스트 주소 판별 방법

## 1. 네트워크 주소

- **호스트 비트가 모두 0**
    
- 서브넷의 시작 주소
    

예:

```
192.168.1.64/26
→ 네트워크 주소
```

---

## 2. 브로드캐스트 주소

- **호스트 비트가 모두 1**
    
- 해당 네트워크의 마지막 주소
    

예:

```
192.168.1.127/26
→ 브로드캐스트
```

---

## 3. 빠른 판별 요령 (시험/실무)

### 블록 크기 사용

1. 서브넷 마스크 확인
    
2. 블록 크기 계산
    
3. 해당 IP가 포함된 범위 확인
    

예:

```
IP: 192.168.1.70/26
블록 크기: 64
→ 64 ~ 127
```

- 네트워크: 64
    
- 브로드캐스트: 127
    
- 사용 가능: 65 ~ 126
    

---

## 4. AND 연산으로 네트워크 주소 구하기

```
IP 주소 AND 서브넷 마스크 = 네트워크 주소
```

예:

```
192.168.1.70
255.255.255.192
----------------
192.168.1.64
```

---

# 4️⃣ 핵심 요약

- CIDR은 프리픽스 길이로 네트워크 표현
    
- 서브네팅 핵심은 **블록 크기 계산**
    
- 네트워크 주소 = 호스트 비트 0
    
- 브로드캐스트 주소 = 호스트 비트 1
    
- 주소 설계는 항상 **요구 호스트 수 → 프리픽스 결정** 순서
