 ## 1️⃣ IP 주소의 기본 개념

IP 주소는 **네트워크 상에서 호스트를 식별하기 위한 논리적 주소(L3 주소)** 이다.

- IPv4 주소 길이: **32비트**
    
- 구성:
    
    - **네트워크 ID** + **호스트 ID**
        
- 목적:
    
    - 네트워크 구분
        
    - 네트워크 내 호스트 식별
        

---

## 2️⃣ IP 주소 표현 방법

### 2-1. 2진수 표현

IP 주소는 내부적으로 **2진수**로 처리된다.

예시:

```
192.168.1.10
= 11000000.10101000.00000001.00001010
```

- 각 옥텟(octet)은 **8비트**
    
- 총 4개의 옥텟 → 32비트
    

---

### 2-2. 10진수 점 표기법 (Dotted Decimal Notation)

사람이 읽기 쉽도록 **8비트 단위로 나누어 10진수로 변환**한 표현 방식이다.

형식:

```
X.X.X.X
```

범위:

- 각 X: **0 ~ 255**
    

예시:

```
10.0.0.1
172.16.0.1
192.168.1.1
```

---

## 3️⃣ IP 클래스(Classful Addressing)

초기의 IPv4 주소 설계에서는 **클래스 기반으로 네트워크와 호스트 영역을 고정 분리**했다.

---

## 4️⃣ IP 클래스별 구조

|클래스|첫 옥텟 범위|네트워크 / 호스트 비트|기본 서브넷 마스크|용도|
|---|---|---|---|---|
|A|1 ~ 126|8 / 24|255.0.0.0 (/8)|대규모 네트워크|
|B|128 ~ 191|16 / 16|255.255.0.0 (/16)|중간 규모|
|C|192 ~ 223|24 / 8|255.255.255.0 (/24)|소규모 네트워크|
|D|224 ~ 239|-|-|멀티캐스트|
|E|240 ~ 255|-|-|실험/예약|

---

## 5️⃣ 클래스 구분 기준 (이진 패턴)

IP 클래스는 **첫 번째 옥텟의 비트 패턴**으로 구분된다.

|클래스|이진 시작 패턴|
|---|---|
|A|0xxxxxxx|
|B|10xxxxxx|
|C|110xxxxx|
|D|1110xxxx|
|E|1111xxxx|

---

## 6️⃣ 클래스별 주소 개수 개념

### Class C 예시

- 호스트 비트: 8비트
    
- 사용 가능 호스트 수:
    

```
2⁸ - 2 = 254
```

제외되는 주소:

- 네트워크 주소 (모두 0)
    
- 브로드캐스트 주소 (모두 1)
    

---

## 7️⃣ 사설 IP 주소 대역 (중요)

클래스 구조 안에서 **사설 네트워크용으로 예약된 주소 범위**가 있다.

|클래스|사설 IP 대역|
|---|---|
|A|10.0.0.0 ~ 10.255.255.255|
|B|172.16.0.0 ~ 172.31.255.255|
|C|192.168.0.0 ~ 192.168.255.255|

---

## 8️⃣ 클래스 방식의 한계

- 주소 낭비 심각
    
- 네트워크 크기 조절 불가
    
- 현재는 **CIDR(Classless Inter-Domain Routing)** 방식 사용
    

예시:

```
192.168.1.0/27
```

→ 클래스 개념 무시, **프리픽스 길이로 네트워크 크기 결정**

---

## 9️⃣ 핵심 요약

- IP 주소는 32비트 논리 주소
    
- 사람이 보기 쉽게 점 표기법 사용
    
- 과거에는 클래스 기반 분류
    
- 현재는 CIDR 기반 주소 할당
    
- 클래스 개념은 **이해를 위한 기초 개념**으로 중요
