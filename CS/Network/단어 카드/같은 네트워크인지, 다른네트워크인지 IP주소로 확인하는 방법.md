## 판단 기준 한 줄 요약

두 IP를 각각 서브넷 마스크로 AND 연산했을 때  
나오는 네트워크 주소가 같으면 같은 네트워크,  
다르면 다른 네트워크이다.

---

## 1. 필요한 정보

- IP 주소 A
    
- IP 주소 B
    
- 서브넷 마스크 (반드시 필요)
    

---

## 2. 판단 절차 (실무 순서)

### ① IP 주소 A의 네트워크 주소 구하기

```
IP A        : 192.168.1.10
Subnet Mask : 255.255.255.0 (/24)

→ 네트워크 주소: 192.168.1.0
```

IP 주소와 서브넷 마스크를 AND 연산하여 네트워크 주소를 구한다.

---

### ② IP 주소 B의 네트워크 주소 구하기

```
IP B        : 192.168.1.50
Subnet Mask : 255.255.255.0 (/24)

→ 네트워크 주소: 192.168.1.0
```

마찬가지로 IP 주소와 서브넷 마스크를 AND 연산한다.

---

### ③ 네트워크 주소 비교

```
192.168.1.0 == 192.168.1.0
```

두 네트워크 주소가 같으므로 같은 네트워크이다.

---

## 3. 다른 네트워크 예시

```
IP A : 192.168.1.10
IP B : 192.168.2.10
Mask : 255.255.255.0
```

- IP A의 네트워크 주소: 192.168.1.0
    
- IP B의 네트워크 주소: 192.168.2.0
    

네트워크 주소가 다르므로 다른 네트워크이며, 통신 시 라우터가 필요하다.

---

## 4. 서브넷 마스크가 다른 경우

```
IP A : 192.168.1.10 /24
IP B : 192.168.1.50 /25
```

- IP A의 네트워크 주소: 192.168.1.0
    
- IP B의 네트워크 주소: 192.168.1.0 또는 192.168.1.128
    

IP 대역이 같아 보여도 서브넷 마스크가 다르면 서로 다른 네트워크로 판단될 수 있다.  
항상 각 IP에 설정된 서브넷 마스크 기준으로 계산해야 한다.

---

## 5. 컴퓨터가 실제로 수행하는 동작

컴퓨터는 통신 시 내부적으로 다음 순서를 따른다.

1. 목적지 IP 주소에 자신의 서브넷 마스크를 AND 연산한다.
    
2. 그 결과가 자신의 네트워크 주소와 같으면  
    → 같은 네트워크로 판단하고 ARP 요청을 보낸다.
    
3. 다르면  
    → 다른 네트워크로 판단하고 기본 게이트웨이로 패킷을 전송한다.
    

---

## 6. 시험 및 실무 핵심 공식

```
(IP 주소) AND (서브넷 마스크) = 네트워크 주소
```

---

## 7. 빠른 감각 체크 팁

- /24: 앞의 3옥텟이 같으면 같은 네트워크
    
- /16: 앞의 2옥텟이 같으면 같은 네트워크
    
- /8: 앞의 1옥텟이 같으면 같은 네트워크
    

이 기준은 빠른 판단용이며, 정확한 판단은 항상 AND 연산으로 수행해야 한다.
