- **같은 AS 내부에서만 사용**
    
- 빠른 수렴과 효율적인 경로 계산이 목적

## ICP 라우팅 방식
### 거리 벡터 방식 (Distance Vector)

#### 대표 프로토콜: RIP

- 거리 기준: **홉 수**
    
- 가장 홉 수가 적은 경로 선택
    
- 최대 홉 수 제한 (RIP: 15)
    

#### 특징

- 구현 단순
    
- 대규모 네트워크에 부적합
    
- 수렴 속도 느림
    

#### 라우팅 테이블 생성

- 이웃 라우터로부터 경로 정보 수신
    
- 홉 수 계산 후 가장 짧은 경로 저장

---

### 링크 상태 방식 (Link State)

#### 대표 프로토콜: OSPF

- 각 라우터가 **네트워크 전체 구조를 그래프로 구성**
    
- 최단 경로 알고리즘 사용 (Dijkstra)
    

#### 동작 흐름

1. 각 라우터가 자신의 링크 상태를 광고
    
2. 모든 라우터가 동일한 **LSDB(Link State Database)** 유지
    - 대역폭이 높은 링크가 메트릭이 낮은 경로로 인식
3. 최단 경로 계산
    
4. 결과를 라우팅 테이블에 반영
    

#### 특징

- 빠른 수렴
    
- 대규모 네트워크에 적합
    
- 메트릭 기반 최적 경로 선택
