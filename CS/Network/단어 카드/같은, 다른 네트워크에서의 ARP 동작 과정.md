# 같은 네트워크에서의 ARP

## 전제 조건

- 송신지와 목적지가 동일한 서브넷에 존재
    
- 서브넷 마스크 적용 결과 네트워크 주소가 동일
    

### 예시

```
PC A: 192.168.1.10/24
PC B: 192.168.1.20/24
```

---

## 동작 과정

### 1. 목적지 판단 (L3)

PC A는 목적지 IP 주소에 자신의 서브넷 마스크를 적용하여  
목적지가 **같은 네트워크**임을 판단한다.

---

### 2. ARP 요청 (Broadcast)

PC A는 목적지 호스트의 MAC 주소를 알지 못하므로 ARP 요청을 전송한다.

- 질의 내용  
    “192.168.1.20 IP를 사용하는 장비는 누구인가”
    
- 목적 MAC 주소  
    FF:FF:FF:FF:FF:FF
    
- 전송 범위  
    같은 LAN(브로드캐스트 도메인) 전체
    

---

### 3. ARP 응답 (Unicast)

PC B는 자신의 IP 주소와 일치함을 확인한 뒤  
자신의 MAC 주소를 PC A에게 유니캐스트로 응답한다.

---

### 4. ARP 캐시 저장

PC A는 다음 정보를 ARP 캐시에 저장한다.

```
192.168.1.20 → PC B의 MAC 주소
```

---

### 5. 실제 데이터 전송

- IP 목적지 주소: 192.168.1.20
    
- MAC 목적지 주소: PC B의 MAC
    

스위치는 MAC 주소를 기준으로 프레임을 전달한다.

---

## 같은 네트워크에서의 핵심 정리

- ARP 대상은 최종 목적지 호스트
    
- ARP 브로드캐스트는 서브넷 내부에서만 전파
    
- 라우터는 개입하지 않음
    

---

# 다른 네트워크에서의 ARP

## 전제 조건

- 목적지가 다른 서브넷에 존재
    
- 디폴트 게이트웨이(라우터)가 존재
    

### 예시

```
PC A: 192.168.1.10/24
PC B: 10.0.0.20/24
Gateway: 192.168.1.1
```

---

## 동작 과정

### 1. 목적지 판단 (L3)

PC A는 목적지 IP 주소(10.0.0.20)에 서브넷 마스크를 적용한 결과  
**다른 네트워크**임을 판단한다.

---

### 2. ARP 대상 결정 (중요)

PC A는 목적지 호스트(PC B)의 MAC 주소를 직접 구하지 않는다.

대신, **다음 홉인 디폴트 게이트웨이의 MAC 주소**가 필요하다.

---

### 3. ARP 요청 (Broadcast)

PC A는 게이트웨이의 IP 주소에 대해 ARP 요청을 전송한다.

- 질의 내용  
    “192.168.1.1 IP를 사용하는 장비는 누구인가”
    
- 목적 MAC 주소  
    FF:FF:FF:FF:FF:FF
    

---

### 4. ARP 응답 (Unicast)

게이트웨이는 자신의 MAC 주소를 PC A에게 유니캐스트로 응답한다.

---

### 5. 실제 데이터 전송

PC A가 전송하는 프레임의 정보는 다음과 같다.

- IP 목적지 주소: 10.0.0.20 (변하지 않음)
    
- MAC 목적지 주소: 게이트웨이의 MAC 주소
    

---

### 6. 라우터 이후 동작

라우터는 패킷을 수신한 후:

1. 목적지 IP 주소 기준으로 라우팅 테이블 조회
    
2. 다음 홉 결정
    
3. 필요 시 다음 네트워크에서 다시 ARP 수행
    
4. 새로운 프레임으로 재캡슐화하여 전달
    

---

## 다른 네트워크에서의 핵심 정리

- ARP 대상은 최종 목적지가 아니라 **다음 홉**
    
- ARP는 항상 같은 네트워크 범위 내에서만 수행
    
- 라우터를 지날 때마다 MAC 주소는 변경됨
    
- IP 주소는 최종 목적지까지 유지됨
    

---

## 전체 비교 요약

|구분|같은 네트워크|다른 네트워크|
|---|---|---|
|ARP 대상|목적지 호스트|디폴트 게이트웨이|
|ARP 범위|같은 서브넷|송신자 서브넷|
|라우터 개입|없음|있음|
|목적지 MAC|최종 호스트|게이트웨이|
|목적지 IP|최종 호스트|최종 호스트|

---

## 한 문장 요약

ARP는 같은 네트워크에서는 목적지의 MAC 주소를 찾고, 다른 네트워크에서는 다음 홉인 게이트웨이의 MAC 주소를 찾기 위해 동작한다.
