### 1. 단편화란 무엇인가

단편화는 **IP 패킷의 크기가 전송 경로의 MTU(Maximum Transmission Unit)보다 클 때**,  
하나의 패킷을 여러 개의 작은 패킷으로 나누어 전송하는 과정이다.

- MTU: 한 번에 전송 가능한 최대 프레임 크기
    
- 대표적인 MTU 예시: Ethernet 환경에서 1500바이트
    

---

### 2. 단편화가 필요한 이유

IP 계층(L3)은 서로 다른 네트워크를 통과한다.  
각 네트워크 구간마다 MTU가 다를 수 있기 때문에, 큰 IP 패킷은 그대로 전달되지 못하는 경우가 있다.

이때 패킷을 나누어 전송하지 않으면:

- 패킷이 폐기됨
    
- 통신 실패 발생
    

이를 방지하기 위해 단편화가 사용된다.

---

### 3. IPv4 단편화 동작 방식

IPv4에서는 **라우터와 송신 호스트 모두 단편화를 수행할 수 있다**.

하나의 IP 패킷이 여러 조각으로 나뉘면, 각 조각은 독립적인 IP 패킷이 되며 다음 필드를 가진다.

#### IPv4 단편화 관련 필드

- 식별자(Identification)
    
    - 원래 하나였던 패킷을 구분하기 위한 값
        
    - 같은 패킷에서 나온 단편들은 동일한 식별자 값을 가진다
        
- 플래그(Flags)
    
    - DF(Don’t Fragment): 1이면 단편화 금지
        
    - MF(More Fragments): 뒤에 단편이 더 있으면 1
        
- 단편화 오프셋(Fragment Offset)
    
    - 원본 데이터에서 해당 단편의 위치
        
    - 8바이트 단위로 표현
        

---

### 4. 단편화 예시 흐름

- 원본 IP 패킷 크기: 4000바이트
    
- 경로 MTU: 1500바이트
    

결과:

- 패킷은 여러 개로 분할됨
    
- 각 단편은:
    
    - 동일한 식별자
        
    - 서로 다른 단편화 오프셋
        
    - 마지막 단편을 제외하고 MF = 1
        

수신 측에서는:

- 식별자 + 오프셋 정보를 이용해
    
- 모든 단편을 재조립하여 원래의 패킷을 복원한다
    

---

### 5. 재조립은 어디서 이루어지는가

- 단편의 재조립은 **목적지 호스트에서만 수행**된다
    
- 중간 라우터에서는 재조립하지 않는다
    

이유:

- 라우터의 부하 증가 방지
    
- 처리 지연 최소화
    

---

### 6. IPv6에서의 단편화

IPv6에서는 설계가 다르다.

- 라우터는 단편화를 수행하지 않는다
    
- 단편화는 **송신 호스트만 수행**한다
    
- 단편화 정보는 기본 헤더가 아닌 **확장 헤더(Fragment Header)**에 포함된다
    

이를 위해:

- Path MTU Discovery(PMTUD)를 사용
    
- 경로상의 최소 MTU를 사전에 파악하여 패킷 크기를 조절한다
    

---

|구분|IPv4|IPv6|
|---|---|---|
|라우터 단편화|가능|불가능|
|송신 호스트 단편화|가능|가능|
|단편화 발생 위치|송신 호스트, 라우터|송신 호스트만|
|단편화 헤더 위치|기본 헤더에 포함|Fragment 확장 헤더|
|단편화 관련 필드|IdentificationFlags (DF, MF)Fragment Offset|IdentificationM 플래그Fragment Offset|
|DF 플래그|존재|없음|
|Path MTU Discovery|선택적|필수|
|MTU 초과 시 라우터 동작|단편화 또는 ICMP|ICMP 오류만 전송|
|재조립 위치|목적지 호스트|목적지 호스트|
|설계 철학|네트워크가 처리|종단 간 처리|

### 7. 단편화의 문제점

- 패킷 수 증가로 인한 오버헤드
    
- 단편 중 하나라도 유실되면 전체 패킷 폐기
    
- 보안 장비 및 방화벽 처리 복잡도 증가
    

이 때문에 현대 네트워크에서는:

- 단편화를 최소화하고
    
- MTU 기반 설계를 권장한다
    

---

### 8. 핵심 요약

- 단편화는 MTU보다 큰 IP 패킷을 나누는 과정이다
    
- IPv4: 라우터와 호스트가 단편화 가능
    
- IPv6: 송신 호스트만 단편화 가능
    
- 재조립은 목적지에서만 수행된다
