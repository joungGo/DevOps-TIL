#### 대표 프로토콜: BGP

- **AS 간 라우팅** 담당
    
- 인터넷의 핵심 라우팅 프로토콜
    

---
## EGP 라우팅 방법
### BGP 특징

- 경로 벡터 기반
    
- “가장 짧은 경로”가 아닌 “정책 기반 경로 선택”
    
- AS 간 라우터 통신에 사용
    

### ASBR (AS Boundary Router)

- 서로 다른 AS를 연결하는 라우터
    
- BGP를 수행하는 라우터
    

### 라우팅 테이블 반영

- AS 경로, 정책, 우선순위를 고려해 경로 선택
    
- 내부 라우팅 테이블로 전달 가능
