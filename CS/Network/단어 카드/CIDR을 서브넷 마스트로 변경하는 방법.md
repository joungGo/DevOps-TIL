## 1️⃣ CIDR 표기법이 의미하는 것

예시:

```
/26
```

의미:

- **앞에서부터 26비트가 네트워크 비트**
    
- 나머지는 호스트 비트
    

IP는 총 **32비트**:

```
11111111.11111111.11111111.11000000
```

---

## 2️⃣ 변환 방법 (핵심 규칙)

### 🔹 규칙 1

- 8비트 단위(옥텟)로 끊는다
    

### 🔹 규칙 2

- 네트워크 비트는 `1`
    
- 호스트 비트는 `0`
    

---

## 3️⃣ 단계별 변환 예시

### 예제 1️⃣ `/24`

```
11111111.11111111.11111111.00000000
```

→ 10진수 변환

```
255.255.255.0
```

---

### 예제 2️⃣ `/26`

```
11111111.11111111.11111111.11000000
```

마지막 옥텟:

```
11000000
= 128 + 64 = 192
```

👉 결과:

```
255.255.255.192
```

---

### 예제 3️⃣ `/20`

```
11111111.11111111.11110000.00000000
```

세 번째 옥텟:

```
11110000
= 128 + 64 + 32 + 16 = 240
```

👉 결과:

```
255.255.240.0
```

---

## 4️⃣ 자주 쓰는 CIDR ↔ 서브넷 마스크 표

|CIDR|서브넷 마스크|
|---|---|
|/8|255.0.0.0|
|/16|255.255.0.0|
|/20|255.255.240.0|
|/24|255.255.255.0|
|/26|255.255.255.192|
|/27|255.255.255.224|
|/28|255.255.255.240|

---

## 5️⃣ 빠르게 계산하는 요령 (시험/실무)

마지막 옥텟 값 공식:

```
256 - 2^(호스트 비트 수)
```

예) `/26`

- 호스트 비트: 6
    
- 256 - 2⁶ = 256 - 64 = **192**
    

---

## 6️⃣ 한 줄 정리

> **CIDR 숫자는 네트워크 비트 개수이고, 이를 앞에서부터 1로 채워 8비트씩 끊어 10진수로 바꾸면 서브넷 마스크다.**

다음으로 이어서 볼까?

- CIDR 보고 네트워크 주소 바로 구하는 법
    
- 서브넷 범위(첫 IP / 마지막 IP) 계산법
    
- 시험 문제 푸는 공식 패턴
