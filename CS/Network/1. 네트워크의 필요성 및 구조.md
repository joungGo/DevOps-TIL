### 개발과 네트워크 개요 정리

**개발**

- 새로운 기능 구현을 위해 통신 개념 이해 필요
    
- 통신 구조 이해를 통한 적합한 구현 가능
    
- 리팩토링 시 오류 원인 분석 능력 필요
    
- 네트워크 흐름 이해를 통한 문제 해결 가능
    

**네트워크 정의**

- 여러 장치를 연결하여 정보를 공유하는 통신망
    

**네트워크 구성 요소**

- 호스트
    
    - 클라이언트와 서버 역할 수행 주체
        
    - 각 노드가 클라이언트와 서버 역할 모두 수행 가능
        
- 메시지
    
    - 호스트 간 전달되는 데이터
        
- 네트워크 장비
    
    - 허브
        
    - 리피터
        
    - 라우터
        
- 통신 매체
    
    - 장치 간 연결 경로
        
    - 간선 또는 링크
        
    - 유선 매체
        
    - 무선 매체
