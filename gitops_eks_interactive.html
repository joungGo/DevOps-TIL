👨‍💻 Developer

애플리케이션 코드를 작성하고 Git 저장소에 푸시하는 개발자입니다.

주요 역할:

  • 소스 코드 작성 및 수정
  • 로컬 환경에서 테스트
  • git push로 변경사항 배포 트리거
GitOps CI/CD

📁 Source Code Repository

애플리케이션 소스 코드와 Kubernetes 매니페스트가 저장된 GitHub 저장소입니다.

포함 내용:

  • 애플리케이션 소스 코드
  • Dockerfile
  • Helm Chart 및 values 파일
  • ArgoCD Application 정의
Git GitOps

⚙️ GitHub Actions

CI/CD 파이프라인을 실행하는 GitHub의 자동화 서비스입니다.

수행 작업:

  • 코드 빌드 및 테스트
  • Docker 이미지 빌드
  • OIDC를 통한 AWS 인증
  • ECR에 이미지 푸시
  • values.prod.yaml 이미지 태그 업데이트
CI OIDC ECR

📄 application.yaml

ArgoCD가 모니터링할 애플리케이션을 정의하는 CRD입니다.

설정 내용:

  • Git 저장소 URL 및 브랜치
  • 배포 대상 클러스터 및 네임스페이스
  • Sync 정책 (자동/수동)
  • Health check 설정
ArgoCD GitOps

📝 values.prod.yaml

프로덕션 환경용 Helm 값 파일입니다.

주요 설정:

  • 이미지 태그 (CI에서 자동 업데이트)
  • 리소스 요청/제한
  • 환경 변수
  • Replica 수
Helm Production

📦 Helm Chart

url-shortener 애플리케이션의 Kubernetes 리소스 템플릿입니다.

포함 리소스:

  • Deployment
  • Service
  • Ingress
  • HPA
  • ConfigMap / Secret
Helm K8s

설정 내용:

  • EC2NodeClass: AMI, 보안그룹
  • Spot/On-demand 비율
  • Consolidation 정책
Karpenter GitOps

📂 cluster-addons/karpenter/

  • IRSA 서비스 어카운트
Karpenter ArgoCD

장점:

  • 임시 토큰 자동 발급

IAM Security

👤 github-actions-role

GitHub Actions 워크플로우가 assume하는 IAM Role입니다.

권한:

  • EKS 클러스터 접근 (선택)

Trust Policy: GitHub OIDC Provider

IAM ECR

🔑 alb-controller-role (IRSA)

권한:

  • 타겟그룹 관리
  • 보안그룹 규칙 관리
  • ACM 인증서 조회
IRSA ALB

🔑 karpenter-controller-role

권한:

  • EC2 인스턴스 실행/종료
  • 가격 조회
  • SQS 메시지 수신
  • PassRole (NodeRole)
IRSA Karpenter

🖥️ KarpenterNodeRole

포함 정책:

  • AmazonEKS_CNI_Policy
  • AmazonEC2ContainerRegistryReadOnly
  • AmazonSSMManagedInstanceCore
IAM Node

🚪 EKS Access Entry

Karpenter 노드가 EKS 클러스터에 참여할 수 있도록 허용하는 설정입니다.

EKS Karpenter

🐳 ECR Repository

url-shortener 애플리케이션 이미지를 저장하는 컨테이너 레지스트리입니다.

기능:

  • 이미지 스캔 (취약점 탐지)
  • 수명 주기 정책
  • 암호화 (KMS)
  • 교차 리전 복제 (선택)
AWS Container

📨 SQS Queue

EC2 Spot 인스턴스 중단 알림을 수신하는 큐입니다.

동작 방식:

  • EventBridge에서 Spot 중단 이벤트 수신
  • Karpenter가 큐를 폴링
  • 중단 전 Pod를 다른 노드로 이동
  • Graceful 종료 보장
AWS Spot

🌐 ALB (Application Load Balancer)

인터넷에서 들어오는 트래픽을 처리하는 L7 로드밸런서입니다.

기능:

  • Host/Path 기반 라우팅
  • SSL/TLS 종료
  • WAF 연동
  • 타겟그룹 헬스체크
Public L7

🎛️ ALB Controller

Kubernetes Ingress 리소스를 감시하고 AWS ALB를 자동으로 관리합니다.

동작:

  • Ingress 생성 → ALB 프로비저닝
  • Ingress 삭제 → ALB 삭제
  • 어노테이션으로 세부 설정

설치: Helm (직접 설치)

kube-system IRSA

🌍 CoreDNS

클러스터 내부 DNS 서버입니다.

기능:

  • Service 이름 → ClusterIP 해석
  • Pod DNS 정책 처리
  • 외부 DNS 포워딩

관리: EKS 애드온

kube-system Add-on

🚀 Karpenter

Pod 요구사항에 맞는 노드를 자동으로 프로비저닝하는 노드 오토스케일러입니다.

장점:

  • 빠른 노드 프로비저닝 (~30초)
  • Spot 인스턴스 자동 활용
  • 노드 통합 (Consolidation)
  • 다양한 인스턴스 타입 지원

설치: ArgoCD로 GitOps 관리

동작:

  • 변경사항 감지 시 자동 Sync

  • 롤백 및 히스토리 관리
GitOps CD

🏗️ Terraform

AWS 인프라를 코드로 관리하는 IaC 도구입니다.

관리 리소스:

  • VPC, 서브넷, 라우팅
  • EKS 클러스터
  • ECR 레포지토리
  • IAM Role/Policy
  • SQS 큐
IaC AWS

🔧 API Pod

url-shortener 애플리케이션을 실행하는 Pod입니다.

설정:

  • Replica: 2 (고가용성)
  • HPA로 자동 스케일링
  • Liveness/Readiness 프로브
  • 리소스 제한 설정
Workload Deployment

🗄️ PostgreSQL

URL 단축 데이터를 저장하는 데이터베이스입니다.

설정:

  • StatefulSet으로 배포
  • PVC로 영구 스토리지
  • Secret으로 비밀번호 관리
Database StatefulSet

📈 HPA (Horizontal Pod Autoscaler)

CPU 사용량을 기반으로 Pod를 자동 스케일링합니다.

설정:

  • Target CPU: 70%
  • Min Replicas: 2
  • Max Replicas: 10

Pod가 스케일아웃되면 Karpenter가 필요시 새 노드를 추가합니다.

Autoscaling Karpenter

🔗 Service

API Pod에 대한 네트워크 접근을 제공하는 ClusterIP 서비스입니다.

설정:

  • Type: ClusterIP
  • Port: 80 → 8080
  • Label Selector로 Pod 연결
Networking K8s

🚪 Ingress

외부 트래픽을 서비스로 라우팅하는 규칙입니다.

설정:

  • IngressClass: alb
  • Host/Path 기반 라우팅
  • TLS 설정 (ACM 인증서)

ALB Controller가 이 리소스를 감시하고 ALB를 생성합니다.

Networking ALB

🔒 Secret

데이터베이스 비밀번호 등 민감한 정보를 저장합니다.

사용:

  • PostgreSQL 접속 정보
  • 환경변수로 Pod에 주입
  • Base64 인코딩 저장
Security K8s

🌐 ArgoCD Ingress

ArgoCD UI에 외부 접근을 제공하는 Ingress입니다.

설정:

  • Host: argocd.example.com
  • TLS 종료
  • ALB를 통한 라우팅
ArgoCD ALB

🖥️ On-demand Node

EKS 관리형 노드 그룹의 기존 노드입니다.

특징:

  • 안정적인 가용성
  • 예측 가능한 비용
  • 기본 시스템 Pod 실행
EC2 Managed

⚡ Karpenter Node

Karpenter가 동적으로 프로비저닝한 노드입니다.

특징:

  • Spot 인스턴스 우선 사용 (비용 절감)
  • Pod 요구사항에 최적화된 인스턴스 타입
  • 빠른 스케일링 (~30초)
  • 자동 Consolidation
Karpenter Spot

🌍 Internet

외부 사용자가 서비스에 접근하는 시작점입니다.

트래픽 흐름:

  • 사용자 → ALB (HTTP/HTTPS)
  • ALB → Ingress 라우팅 규칙
  • Ingress → Service → Pod
