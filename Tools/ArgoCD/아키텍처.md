### 핵심 흐름 요약

| 단계    | 액션                                      | 결과                  |
| ----- | --------------------------------------- | ------------------- |
| **1** | 코드 수정 → `docker buildx build`           | 새 이미지 생성            |
| **2** | ECR에 `sha-xxxxxxx` 태그로 Push             | 이미지 저장됨             |
| **3** | `values.prod.yaml` 태그 업데이트 → `git push` | GitOps Repo 변경      |
| **4** | ArgoCD가 변경 감지 → **OutOfSync**           | Manual Sync 대기      |
| **5** | Sync 실행 → Deployment 생성                 | Pod가 ECR에서 이미지 Pull |
| **6** | PostgreSQL Pod → PVC(EBS) 연결            | 데이터 영속 저장           |
