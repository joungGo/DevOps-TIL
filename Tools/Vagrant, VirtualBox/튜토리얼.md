## 1. Vagrant란?

**Vagrant**는  
👉 **가상 개발 환경을 쉽고 빠르게 생성·관리할 수 있도록 도와주는 자동화 도구**입니다.

### 핵심 개념

- 개발 환경을 **코드로 정의(Infrastructure as Code)**
    
- 동일한 환경을 여러 사람, 여러 PC에서 **똑같이 재현 가능**
    
- 가상머신 생성, 네트워크 설정, 패키지 설치 등을 자동화
    

### 주요 기능

- `Vagrantfile` 하나로 환경 정의
    
- 명령어 몇 개로 가상머신 생성/삭제
    
    ```bash
    vagrant up      # 가상머신 생성 및 실행
    vagrant halt    # 가상머신 중지
    vagrant destroy # 가상머신 삭제
    ```
    
- 쉘 스크립트, Ansible 등으로 **프로비저닝** 가능
    

### 언제 사용하나?

- 개발자마다 환경이 달라 생기는 오류 방지
    
- 로컬에서 서버 환경(Linux, DB, 웹서버 등) 재현
    
- 팀 프로젝트, 교육, 테스트 환경 구축

## 2. VirtualBox란?

**VirtualBox**는  
👉 **하나의 물리적 컴퓨터에서 여러 운영체제를 실행할 수 있게 해주는 가상화 소프트웨어(하이퍼바이저)**입니다.

### 핵심 개념

- 실제 PC 위에 **가상 컴퓨터(VM)** 생성
    
- Windows에서 Linux, macOS 환경을 동시에 사용 가능
    
- Oracle에서 제공하는 무료 오픈소스 가상화 도구
    

### 주요 기능

- 다양한 OS 지원 (Linux, Windows 등)
    
- 스냅샷 기능 (상태 저장/복원)
    
- 네트워크, 디스크, 메모리 설정 가능
    
- GUI 기반 관리
    

### 언제 사용하나?

- 다른 OS 테스트
    
- 서버 환경 실습
    
- 보안 실험, 교육용 실습
    

---

## 3. Vagrant와 VirtualBox의 관계

|구분|역할|
|---|---|
|**VirtualBox**|가상머신을 실제로 실행하는 엔진|
|**Vagrant**|가상머신을 쉽게 만들고 관리하는 자동화 도구|

📌 **Vagrant는 VirtualBox 위에서 동작**하는 경우가 가장 많음  
(다른 Provider: VMware, Hyper-V 등도 가능)

### 예시 흐름

1. 사용자가 `vagrant up` 실행
    
2. Vagrant가 VirtualBox를 호출
    
3. VirtualBox가 가상머신 생성
    
4. Vagrant가 OS 설정 및 프로비저닝 자동 수행
    
---
## 4. Vagrant 동작

- Box 이미지
	- 운영체제가 압축되어서 이미지의 형태로 압축되어 있는 형태를 지칭하는 용어입니다.
- 프로젝트 최상위 디렉토리에 Vagrantfile 파일 생성/수정
- 프로젝트를 위한 Vagrant 가상 인스턴스(VM) 시작
- 가상 인스턴스 접속 및 작업
- 가상 인스턴스 종료
---

## 5. 한 줄 요약

- **VirtualBox**: 가상머신을 실행하는 도구
    
- **Vagrant**: 가상머신 환경을 코드로 정의하고 자동 생성하는 도구
    

👉 **“VirtualBox는 엔진, Vagrant는 자동 운전 시스템”**이라고 이해하면 쉽다.**
