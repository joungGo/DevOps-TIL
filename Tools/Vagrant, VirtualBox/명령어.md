아래는 **자주 사용하는 Vagrant 명령어**를 중심으로, **간단한 설명과 함께 표로 정리**한 내용입니다.

|명령어|설명|
|---|---|
|`vagrant init`|현재 디렉토리에 **Vagrantfile 생성** (가상머신 설정 파일)|
|`vagrant up`|Vagrantfile 기준으로 **가상머신 생성 및 부팅**|
|`vagrant halt`|실행 중인 가상머신을 **정상 종료**|
|`vagrant reload`|가상머신을 **재부팅** (Vagrantfile 변경 시 유용)|
|`vagrant suspend`|가상머신을 **일시 정지** (상태 저장)|
|`vagrant resume`|일시 정지된 가상머신을 **다시 실행**|
|`vagrant destroy`|가상머신을 **완전히 삭제** (데이터도 삭제)|
|`vagrant status`|현재 가상머신의 **상태 확인**|
|`vagrant ssh`|가상머신에 **SSH 접속**|
|`vagrant provision`|프로비저닝 스크립트만 **다시 실행**|
|`vagrant box add`|새로운 **box(OS 이미지) 추가**|
|`vagrant box list`|로컬에 저장된 **box 목록 확인**|
|`vagrant box remove`|등록된 **box 삭제**|
|`vagrant plugin install`|Vagrant **플러그인 설치**|
|`vagrant plugin list`|설치된 **플러그인 목록 확인**|
|`vagrant global-status`|전체 Vagrant 가상머신 **목록 및 상태 확인**|
|`vagrant snapshot save`|현재 상태를 **스냅샷으로 저장**|
|`vagrant snapshot list`|저장된 **스냅샷 목록 확인**|
|`vagrant snapshot restore`|스냅샷 상태로 **되돌리기**|

### 📌 초보자 핵심 조합

- 처음 시작: `vagrant init` → `vagrant up`
    
- 접속: `vagrant ssh`
    
- 설정 변경 후: `vagrant reload`
    
- 정리: `vagrant halt` 또는 `vagrant destroy`

또는 **Kubernetes / 멀티노드 Vagrant 운영 팁**까지 정리해드릴게요.
