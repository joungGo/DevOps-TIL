## 1️⃣ 가상화(Virtualization)란?

> **하나의 물리적인 머신에서 여러 개의 운영체제를 실행하는 기술**

### 🔹 핵심 의미

- **물리적인 머신**: 실제 컴퓨터 1대 (CPU, 메모리, 디스크를 가진 서버)
    
- 그 **한 대의 컴퓨터 위에서**
    
- **여러 개의 독립적인 운영체제(OS)** 를 동시에 실행
    

📌 예시

- 실제 서버 1대
    
    - VM1: Linux
        
    - VM2: Windows
        
    - VM3: Ubuntu  
        → 각각 **서로 다른 컴퓨터처럼 동작**
        

👉 빨간 밑줄 친 **“하나의 물리적인 머신”** 이 핵심 포인트  
→ 서버를 여러 대처럼 쪼개서 쓰는 기술

---

## 2️⃣ 클라우드 컴퓨팅에서의 가상화

> 운영체제(OS) 위에서 가상 머신을 생성하는 **하드웨어 가상화**

### 🔹 구조를 단계별로 보면

1. **물리 서버**
    
    - CPU, 메모리, 디스크, 네트워크
        
2. **호스트 OS + 하이퍼바이저**
    
    - 하이퍼바이저: 가상화를 담당하는 소프트웨어  
        (예: VMware, Hyper-V, KVM)
        
3. **가상 머신(VM)**
    
    - 각 VM마다:
        
        - 가상 CPU
            
        - 가상 메모리
            
        - 가상 디스크
            
        - **자기만의 OS**
            

📌 클라우드(AWS, Azure 등)에서 우리가 만드는 EC2, VM 인스턴스 = **가상 머신**

---

## 3️⃣ 가상화의 장점 (중요 ⭐)

### ✅ 1. 유연성

> 동일한 하드웨어에서 여러 운영체제를 동시에 실행

- 서버를 새로 살 필요 ❌
    
- 필요하면 VM을 **즉시 생성 / 삭제**
    
- 개발·테스트·운영 환경 분리 가능
    

📌 예:

- 개발용 Linux
    
- 테스트용 Windows
    
- 운영용 Linux  
    → 한 서버에서 동시에 실행
    

---

### ✅ 2. 민첩성

> 여러 운영체제 간 파일 이동 가능

- VM 간 파일 복사
    
- 스냅샷 기반 백업/복구
    
- 빠른 배포 가능
    

📌 개발 환경 복제 → 새 서버에 바로 적용

---

### ✅ 3. 내결함성 (장애 대응)

> 서버 장애 발생 시 다른 서버로 이전 가능

- VM은 **파일 단위**
    
- 장애 발생 시:
    
    - VM 이미지를
        
    - 정상 서버로 옮겨서 재실행
        

📌 서비스 중단 최소화  
→ 클라우드에서 **고가용성(HA)** 의 핵심

---

### ✅ 4. 비용 절감

> 물리 서버 수 감소 + 자원 재사용

- 서버 여러 대 → 서버 한 대 + VM 여러 개
    
- CPU / 메모리 남는 자원 효율적으로 사용
    
- 전기, 공간, 유지보수 비용 절감
    

📌 기업·클라우드에서 가상화가 필수인 이유

---

## 4️⃣ 한 문장으로 정리하면

> **가상화란, 하나의 물리 서버를 여러 대의 독립된 가상 서버처럼 사용하게 해주는 기술이며,  
> 클라우드 컴퓨팅의 핵심 기반 기술이다.**
