**라운드 로빈(Round Robin)**은 여러 서버(Pod)가 있을 때 **요청을 순서대로 분배하는 방식**이다.

예를 들어 Pod가 3개 있다고 가정한다.

```
Pod A
Pod B
Pod C
```

요청이 들어오면 다음 순서로 전달된다.

```
요청 1 → Pod A
요청 2 → Pod B
요청 3 → Pod C
요청 4 → Pod A
요청 5 → Pod B
요청 6 → Pod C
```

즉 **순환하면서 요청을 나눠 처리**한다.

쿠버네티스에서는

```
Client Pod
   ↓
Service (ClusterIP)
   ↓
Pod A / Pod B / Pod C
```

이 과정에서 **kube-proxy가 여러 Pod로 트래픽을 분산**한다.

라운드 로빈을 사용하는 이유

- 특정 Pod에 요청이 몰리는 것을 방지
    
- 여러 Pod가 동시에 처리 가능
    
- 시스템 처리량 증가
