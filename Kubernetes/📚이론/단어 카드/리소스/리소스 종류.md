# 1. 워크로드 리소스 (애플리케이션 실행)

애플리케이션을 **실행하고 관리하는 리소스**이다.

|리소스|설명|
|---|---|
|Pod|컨테이너가 실행되는 가장 작은 단위|
|Deployment|Pod 배포 및 업데이트 관리|
|ReplicaSet|Pod 개수 유지|
|StatefulSet|상태를 가진 애플리케이션 관리|
|DaemonSet|모든 노드에 Pod 실행|
|Job|한 번 실행되는 작업|
|CronJob|주기적으로 실행되는 작업|

---

# 2. 서비스 리소스 (네트워크)

Pod에 **접근할 수 있도록 네트워크를 제공하는 리소스**이다.

|리소스|설명|
|---|---|
|Service|Pod 접근을 위한 네트워크 서비스|
|Ingress|외부 HTTP/HTTPS 접근 관리|
|Endpoint|Service가 연결된 Pod 정보|

---

# 3. 설정 리소스 (Configuration)

애플리케이션 **설정 정보를 관리하는 리소스**이다.

|리소스|설명|
|---|---|
|ConfigMap|일반 설정 데이터 저장|
|Secret|비밀번호, API 키 등 민감 정보 저장|

---

# 4. 스토리지 리소스

데이터 저장을 위한 리소스이다.

|리소스|설명|
|---|---|
|PersistentVolume (PV)|실제 저장소|
|PersistentVolumeClaim (PVC)|저장소 요청|
|StorageClass|스토리지 종류 정의|

---

# 5. 클러스터 관리 리소스

클러스터 운영과 관리에 관련된 리소스이다.

|리소스|설명|
|---|---|
|Node|클러스터의 서버|
|Namespace|리소스 논리적 구분|
|ServiceAccount|Pod의 인증 계정|
|Role / RoleBinding|권한 관리|

---

# 리소스 종류 확인 명령어

모든 리소스 종류 확인

```bash
kubectl api-resources
```

자주 사용하는 리소스 확인

```bash
kubectl get all
```

---

# 핵심 정리

Kubernetes 리소스는 클러스터에서 관리되는 객체이며 크게 **워크로드(Pod, Deployment), 네트워크(Service, Ingress), 설정(ConfigMap, Secret), 스토리지(PV, PVC), 클러스터 관리(Node, Namespace)** 등의 종류로 나뉜다. Kubernetes는 이러한 리소스를 통해 애플리케이션을 배포하고 관리한다.
