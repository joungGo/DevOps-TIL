# 1. Pod 내부 접속 (kubectl exec)

## macOS / Linux

macOS에서는 대부분 **bash 또는 sh**를 사용한다.

명령어

```bash
kubectl exec -it <pod-name> -- /bin/bash
```

예

```bash
kubectl exec -it nginx-pod -- /bin/bash
```

만약 bash가 없으면

```bash
kubectl exec -it nginx-pod -- /bin/sh
```

설명

- `-i` : 표준 입력 연결
    
- `-t` : 터미널 모드
    
- `--` : 실행할 명령어 구분
    

---

## Windows

Windows에서는 **cmd 또는 PowerShell**을 사용한다.

명령어 (PowerShell / CMD)

```powershell
kubectl exec -it <pod-name> -- powershell
```

또는

```powershell
kubectl exec -it <pod-name> -- cmd
```

리눅스 컨테이너일 경우

```powershell
kubectl exec -it <pod-name> -- /bin/sh
```

# 2. Pod 포트 접근 (Port Forward)

Pod 포트를 **로컬 PC와 연결**하는 방법이다.

## macOS

```bash
kubectl port-forward pod/<pod-name> 8080:80
```

예

```bash
kubectl port-forward pod/nginx-pod 8080:80
```

접속

```
http://localhost:8080
```

---

## Windows

PowerShell / CMD 동일

```powershell
kubectl port-forward pod/<pod-name> 8080:80
```

접속

```
http://localhost:8080
```

---

# 3. Pod 로그 확인 (kubectl logs)

애플리케이션 로그를 확인하는 방법이다.

## macOS

```bash
kubectl logs <pod-name>
```

실시간 로그

```bash
kubectl logs -f <pod-name>
```

---

## Windows

PowerShell / CMD 동일

```powershell
kubectl logs <pod-name>
```

실시간 로그

```powershell
kubectl logs -f <pod-name>
```

---

# 4. Service로 접근 (kubectl expose)

Pod에 **Service를 생성하여 외부 접근**하는 방법이다.

## macOS

```bash
kubectl expose pod nginx-pod --type=NodePort --port=80
```

확인

```bash
kubectl get svc
```

접속

```
NodeIP:NodePort
```

---

## Windows

```powershell
kubectl expose pod nginx-pod --type=NodePort --port=80
```

확인

```powershell
kubectl get svc
```

접속

```
NodeIP:NodePort
```

---

# 정리

|방법|macOS|Windows|
|---|---|---|
|Pod 내부 접속|kubectl exec -it pod -- /bin/bash|kubectl exec -it pod -- powershell|
|포트 포워딩|kubectl port-forward pod 8080:80|kubectl port-forward pod 8080:80|
|로그 확인|kubectl logs pod|kubectl logs pod|
|서비스 생성|kubectl expose pod|kubectl expose pod|

---

핵심 정리

Pod 애플리케이션 접근 방법은 **kubectl exec, kubectl port-forward, kubectl logs, kubectl expose** 등이 있으며 Windows와 macOS 모두 동일한 kubectl 명령을 사용하지만 macOS는 bash/sh, Windows는 PowerShell 또는 cmd 쉘을 사용한다.
