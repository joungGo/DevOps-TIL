# kubectl 명령어 문법 정리

## 1️⃣ 리소스 조회 (get)

|명령어 형식|설명|
|---|---|
|`kubectl get <resource>`|특정 리소스 목록 조회|
|`kubectl get <resource> <name>`|특정 리소스 하나 조회|
|`kubectl get <resource> -n <namespace>`|특정 네임스페이스 조회|
|`kubectl get <resource> -A`|모든 네임스페이스 조회|
|`kubectl get <resource> -o wide`|추가 정보 포함 조회|
|`kubectl get <resource> -o yaml`|YAML 형식 출력|
|`kubectl get <resource> -o json`|JSON 형식 출력|
|`kubectl get <resource> --watch`|실시간 변경 감시|

예

```
kubectl get pods
kubectl get pods -A
kubectl get service web
kubectl get pods -o wide
```

---

# 2️⃣ 리소스 생성 (create)

|명령어 형식|설명|
|---|---|
|`kubectl create -f <file.yaml>`|YAML 파일로 리소스 생성|
|`kubectl create namespace <name>`|Namespace 생성|
|`kubectl create deployment <name> --image=<image>`|Deployment 생성|
|`kubectl create service clusterip <name> --tcp=<port>:<targetPort>`|ClusterIP 서비스 생성|

예

```
kubectl create -f pod.yaml
kubectl create namespace dev
kubectl create deployment nginx --image=nginx
```

---

# 3️⃣ 리소스 적용 (apply)

|명령어 형식|설명|
|---|---|
|`kubectl apply -f <file.yaml>`|리소스 생성 또는 업데이트|
|`kubectl apply -f <directory>`|디렉토리 전체 리소스 적용|

예

```
kubectl apply -f deployment.yaml
kubectl apply -f ./k8s/
```

---

# 4️⃣ 리소스 삭제 (delete)

|명령어 형식|설명|
|---|---|
|`kubectl delete <resource> <name>`|특정 리소스 삭제|
|`kubectl delete -f <file.yaml>`|YAML 파일로 생성된 리소스 삭제|
|`kubectl delete <resource> --all`|해당 리소스 전체 삭제|
|`kubectl delete namespace <name>`|네임스페이스 삭제|

예

```
kubectl delete pod nginx
kubectl delete deployment web
kubectl delete -f deployment.yaml
```

# 5️⃣ 리소스 상세 정보 조회 (describe)

|명령어 형식|설명|
|---|---|
|`kubectl describe <resource> <name>`|리소스 상세 상태 확인|

예

```
kubectl describe pod nginx
kubectl describe node worker1
kubectl describe service web
```

# 6️⃣ Pod 실행 (run)

|명령어 형식|설명|
|---|---|
|`kubectl run <name> --image=<image>`|Pod 생성|
|`kubectl run <name> --image=<image> --port=<port>`|포트 지정 Pod 생성|
|`kubectl run <name> --image=<image> -it --rm -- bash`|임시 Pod 실행 후 shell 접속|

예

```
kubectl run nginx --image=nginx
kubectl run busybox --image=busybox -it --rm -- sh
```

---

# 7️⃣ 로그 확인 (logs)

|명령어 형식|설명|
|---|---|
|`kubectl logs <pod>`|Pod 로그 조회|
|`kubectl logs -f <pod>`|실시간 로그 조회|
|`kubectl logs <pod> -c <container>`|특정 컨테이너 로그|
|`kubectl logs --previous <pod>`|이전 컨테이너 로그|

예

```
kubectl logs nginx
kubectl logs -f nginx
```

---

# 8️⃣ Pod 내부 명령 실행 (exec)

|명령어 형식|설명|
|---|---|
|`kubectl exec <pod> -- <command>`|Pod 내부 명령 실행|
|`kubectl exec -it <pod> -- bash`|bash 접속|
|`kubectl exec -it <pod> -- sh`|shell 접속|

예

```
kubectl exec nginx -- ls
kubectl exec -it nginx -- bash
```

---

# 9️⃣ 파일 복사 (cp)

|명령어 형식|설명|
|---|---|
|`kubectl cp <pod>:<path> <local_path>`|Pod → 로컬 파일 복사|
|`kubectl cp <local_path> <pod>:<path>`|로컬 → Pod 파일 복사|

예

```
kubectl cp nginx:/tmp/test.txt .
kubectl cp ./test.txt nginx:/tmp/
```

# 🔟 리소스 수정 (edit / patch)

|명령어 형식|설명|
|---|---|
|`kubectl edit <resource> <name>`|리소스 직접 수정|
|`kubectl patch <resource> <name> -p '<json>'`|일부 필드 수정|

예

```
kubectl edit deployment nginx
kubectl patch deployment nginx -p '{"spec":{"replicas":3}}'
```

# 12️⃣ 배포 관리 (rollout)

|명령어 형식|설명|
|---|---|
|`kubectl rollout status <resource> <name>`|배포 상태 확인|
|`kubectl rollout history <resource> <name>`|배포 이력 조회|
|`kubectl rollout undo <resource> <name>`|롤백|
|`kubectl rollout restart <resource> <name>`|재시작|

예

```
kubectl rollout status deployment nginx
kubectl rollout undo deployment nginx
```

# 13️⃣ 리소스 사용량 확인 (top)

|명령어 형식|설명|
|---|---|
|`kubectl top nodes`|Node 리소스 사용량|

예

```
kubectl top nodes

```

---

# 14️⃣ 포트 포워딩 (port-forward)

|명령어 형식|설명|
|---|---|
|`kubectl port-forward <resource>/<name> <localPort>:<targetPort>`|로컬 포트를 Pod 또는 Service에 연결|

예

```
kubectl port-forward pod/nginx 8080:80
kubectl port-forward service/web 8080:80
```

---

# 15️⃣ 실행 대기 (wait)

|명령어 형식|설명|
|---|---|
|`kubectl wait --for=condition=<condition> <resource>/<name>`|특정 상태까지 대기|
|`kubectl wait --for=delete <resource>/<name>`|리소스 삭제 대기|
|`kubectl wait --for=condition=ready pod/<name>`|Pod Ready 상태까지 대기|

예

```
kubectl wait --for=condition=ready pod/nginx
kubectl wait --for=delete pod/nginx
```

---

# 16️⃣ 컨텍스트 관리 (config)

|명령어 형식|설명|
|---|---|
|`kubectl config view`|kubeconfig 내용 확인|
|`kubectl config get-contexts`|컨텍스트 목록|
|`kubectl config use-context <name>`|컨텍스트 변경|
|`kubectl config current-context`|현재 컨텍스트|

예

```
kubectl config get-contexts
kubectl config use-context minikube
```
