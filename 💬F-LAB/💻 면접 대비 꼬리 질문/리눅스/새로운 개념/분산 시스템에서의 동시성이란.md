## 1️⃣ 동시성이란 정확히 뭐야?

분산 시스템에서 말하는 **동시성**은  
👉 **“같은 시간에 발생했다”가 아님**

### ✅ 정의

두 이벤트 `a`, `b`가 있을 때

- `a → b` 도 아니고
    
- `b → a` 도 아니면
    

```
a || b   (a와 b는 concurrent)
```

즉,

> **서로 인과관계가 전혀 없는 독립적인 이벤트**

---

### 🚫 오해 주의

- CPU에서 동시에 실행 ❌
    
- 실제 시계 시간이 같음 ❌
    

👉 **오직 메시지(인과관계) 기준**

---

## 2️⃣ happened-before(→) 다시 정리

Lamport가 정의한 관계야.

### 규칙

1. **같은 프로세스**
    
    ```
    a가 b보다 먼저 실행 → a → b
    ```
    
2. **메시지**
    
    ```
    send(m) → receive(m)
    ```
    
3. **추이성**
    
    ```
    a → b, b → c ⇒ a → c
    ```
    

❗ 이 세 규칙으로 **연결되지 않으면 전부 동시성**

---

## 3️⃣ 동시성 예제 (아주 중요)

### 상황

```
P1            P2
 |             |
 a             b
 |             |
```

- a: P1에서 로그 기록
    
- b: P2에서 로그 기록
    
- 메시지 교환 ❌
    

➡ 관계:

```
a → b ❌
b → a ❌
```

### 결론

```
a || b  (동시 이벤트)
```

---

## 4️⃣ Lamport Timestamp에서 동시성 문제

### 예제

```
P1            P2
 |             |
 a (L=1)       b (L=2)
 |             |
```

Lamport 값만 보면

```
L(a) < L(b)
```

❓ 그러면

> a가 b의 원인인가?

👉 **아니다**

Lamport의 보장은 딱 하나야:

```
a → b  ⇒  L(a) < L(b)
```

반대는 ❌

```
L(a) < L(b)  ⇏  a → b
```

---

### ⚠ 왜 이런 일이 생길까?

Lamport Timestamp는

- **모든 이벤트를 한 줄로 세움**
    
- 실제로 독립적인 이벤트도 강제로 순서를 줌
    

➡ **동시성을 “숨김”**

---

## 5️⃣ Vector Clock이 동시성을 어떻게 잡아내나

### 핵심 아이디어

> “각 프로세스가 본 세상을 그대로 기록하자”

---

### 예제 (P1, P2)

초기

```
P1: [0,0]
P2: [0,0]
```

P1에서 이벤트 a

```
P1: [1,0]
```

P2에서 이벤트 b

```
P2: [0,1]
```

---

### 벡터 비교

- a = `[1,0]`
    
- b = `[0,1]`
    

비교하면

```
[1,0] ≤ [0,1] ❌
[0,1] ≤ [1,0] ❌
```

➡ 결론

```
a || b
```

💡 **이게 Lamport로는 절대 못하는 것**

---

## 6️⃣ 시각적으로 보면

### Lamport

```
a (1) --------> b (2)
```

👉 **순서가 있다고 착각**

---

### Vector Clock

```
a [1,0]    b [0,1]
(비교 불가)
```

👉 **서로 독립임을 정확히 표현**

---

## 7️⃣ 왜 동시성 판별이 그렇게 중요할까?

### 1) 분산 DB 충돌 감지

예:

- 사용자 A가 상품 가격 수정
    
- 사용자 B가 동시에 수정
    

👉 Vector Clock:

```
VC1 || VC2 → 충돌(conflict)
```

👉 Lamport:

```
그냥 “누가 먼저”만 있음 → 덮어씀 위험
```

---

### 2) Git이랑 완전 같은 개념

- 서로 다른 브랜치에서 커밋
    
- 공통 조상 없음
    

👉 **동시 커밋**  
👉 merge 필요

---

## 8️⃣ 한 문장으로 다시 요약

- **동시성**  
    👉 “서로 영향을 주지 않은 이벤트”
    
- **Lamport Timestamp**  
    👉 동시 이벤트도 억지로 줄 세운다
    
- **Vector Clock**  
    👉 동시 이벤트를 **동시라고 말해줄 수 있다**
