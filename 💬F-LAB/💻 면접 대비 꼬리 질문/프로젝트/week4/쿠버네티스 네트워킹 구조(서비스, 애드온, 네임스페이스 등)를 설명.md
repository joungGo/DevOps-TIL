**Service 타입** — ClusterIP(내부 전용), NodePort(Node IP:포트), LoadBalancer(ALB/NLB 자동 생성), ExternalName/Headless(특수 케이스) 4가지 구조와 차이점

**Namespace** — kube-system(시스템 컴포넌트), default(기본), 커스텀(앱/팀별 격리) + DNS 이름 규칙

**CoreDNS** — Service 이름 → ClusterIP 변환 과정, DNS 이름 전체 구조, 업스트림 Route53 포워딩

**kube-proxy** — iptables KUBE-SERVICES 체인 구조, DNAT 동작, iptables vs IPVS 비교

**VPC CNI** — ENI + Secondary IP 할당 구조, Overlay vs VPC CNI 비교, Pod 수 제한 이유

**NetworkPolicy** — default-deny-all 패턴, podSelector/namespaceSelector/ipBlock 규칙

**Addon 전체** — Terraform 관리(vpc-cni, coredns, kube-proxy, ebs-csi) vs ArgoCD 관리(ALB controller, autoscaler, prometheus, ArgoCD, cert-manager, external-dns, Karpenter) 역할 분리
