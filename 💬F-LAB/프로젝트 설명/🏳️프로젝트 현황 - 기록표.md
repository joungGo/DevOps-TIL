# 전체 인프라 정리

## 1단계: Karpenter 노드 정리

```
# Karpenter가 만든 노드 먼저 제거 (안하면 terraform destroy 시 꼬임)
kubectl delete nodepool defaultkubectl delete ec2nodeclass default
```

## 2단계: ArgoCD Application 삭제

```
# ArgoCD가 리소스를 재생성하지 못하도록 먼저 삭제
kubectl delete -f url-shortener/k8s/argocd/application.yamlkubectl delete -f cluster-addons/karpenter/application.yamlkubectl delete -f cluster-addons/metric-server/application.yaml
```

## 3단계: ALB (Ingress) 삭제

```
# ALB Controller가 만든 로드밸런서 삭제 (terraform destroy 전에 해야 함)
kubectl delete ingress -n url-shortener --all
kubectl delete ingress -n argocd --all
# ALB가 실제로 삭제될 때까지 대기 (30초~1분)
sleep 30
```

## 4단계: ALB Controller 삭제

```
helm uninstall aws-load-balancer-controller -n kube-system
```

## 5단계: terraform destroy

```
cd terraformterraform destroy -auto-approve
```

---

> **주의**: 3단계(Ingress 삭제)를 건너뛰면 AWS에 ALB가 남아서 과금이 계속됩니다. terraform destroy로도 안 지워집니다.
