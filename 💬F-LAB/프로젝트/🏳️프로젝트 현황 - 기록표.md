**1. Terraform apply**

```bash
cd /Users/jounghyeon/개발/Url-Shortener-EKS-Platform/terraform
terraform apply
```

**2. kubeconfig 업데이트**

EKS 클러스터가 새로 생성되면 API Endpoint 주소가 새로 바뀜. 그래서 아래 명령어를 통해 이전 주소를 가리키고 있는 kubeconfig 내용을 업데이트 해야 함.

```bash
aws eks update-kubeconfig --region ap-northeast-2 --name urlshortener
```

**3. ALB Controller 설치**

ALB Controller의 **IRSA 역할(IAM Role)**은 Terraform으로 생성되지만, **ALB Controller 자체 설치(Helm)**는 Terraform으로 하지 않고 직접 합니다.

> TODO: 이것도 ArgoCD Application으로 Git에 선언해서 자동 설치하게 수정해야 함!

```bash
helm repo add eks https://aws.github.io/eks-charts
helm repo update

CLUSTER_NAME=$(cd /Users/jounghyeon/개발/Url-Shortener-EKS-Platform/terraform && terraform output -raw eks_cluster_name)
ALB_ROLE_ARN=$(cd /Users/jounghyeon/개발/Url-Shortener-EKS-Platform/terraform && terraform output -raw alb_controller_role_arn)

helm upgrade --install aws-load-balancer-controller eks/aws-load-balancer-controller \
  -n kube-system \
  --set clusterName=${CLUSTER_NAME} \
  --set serviceAccount.create=true \
  --set serviceAccount.name=aws-load-balancer-controller \
  --set serviceAccount.annotations."eks\.amazonaws\.com/role-arn"=${ALB_ROLE_ARN}
```

**4. ArgoCD 설치**

```bash
helm repo add argo https://argoproj.github.io/argo-helm
helm repo update

helm upgrade --install argocd argo/argo-cd \
  -n argocd \
  --create-namespace \
  --set "server.extraArgs[0]=--insecure"
```

**8. ArgoCD Sync 및 확인**

```bash

kubectl -n argocd get secret argocd-initial-admin-secret \
  -o jsonpath="{.data.password}" | base64 -d

kubectl get pods -n url-shortener

# API 확인
ALB_DNS=$(kubectl get ingress -n url-shortener \
  -o jsonpath='{.items[0].status.loadBalancer.ingress[0].hostname}')

```

**9. Karpenter 설치** (eksctl로 노드 Role 등록 후)

```bash
eksctl create iamidentitymapping \
  --cluster urlshortener \
  --region ap-northeast-2 \
  --arn "$(cd terraform && terraform output -raw karpenter_node_role_arn)" \
  --group system:bootstrappers,system:nodes \
  --username system:node:{{EC2PrivateDNSName}}

kubectl apply -f cluster-addons/karpenter/application.yaml
```
