### 멘토링 프로그램 개요

- 총 4개월 과정으로 진행
- 첫 달은 이론과 이력서 중심으로 학습
- 4-5주차부터 개인 맞춤형 프로젝트 시작 예정
- 프로젝트 진행 중에도 이론 학습 병행 (매주 15-20분)
- 멘토링 방식: 일방적 강의가 아닌, 멘티의 자기주도 학습을 돕는 방향성 제시

### 멘토 소개

- 8년 경력 DevOps 엔지니어
- 스타트업 → 해외 보안 클라우드 → 네이버 검색팀 SRE (3년) → 현재 블록체인 업계 시니어 DevOps

### 멘티 배경

- 백엔드 부트캠프 6개월 수료 후 SI 회사에서 백엔드 엔지니어로 약 7개월 근무 (2024년 3월-10월)
- SI 회사에서 수습 3개월 포함, 사내 게시판 기능 구현 및 Grafana/Prometheus 트래픽 시각화 작업 수행
- Java Spring Boot 기반 프로젝트 경험, TypeScript도 일부 사용
- 정보통신공학과 + 컴퓨터공학 복수전공

### 커리어 목표 및 업계 인사이트

- 최종 목표: 클라우드 엔지니어, 현재는 DevOps로 시작하여 경험 쌓기 희망
- 글로벌 서버 환경에서의 트래픽 처리 경험에 관심
- **멘토의 중요한 조언**: 클라우드 엔지니어, DevOps 엔지니어, SRE는 본질적으로 동일한 직군
- 클라우드 엔지니어 공고는 오히려 적고, DevOps가 더 포괄적인 직군
- 현재 대부분의 회사들이 AWS/GCP + Kubernetes + Grafana 모니터링 스택으로 표준화됨
- DevOps는 원래 직군이 아닌 문화였으나, 현재는 독립된 직군으로 자리잡음

### 취업 준비 전략

- 단순히 "사수가 있는 회사"가 아닌, 구체적인 도메인 목표 설정 필요
- 도메인에 따라 DevOps 업무 성격이 달라짐 (예: 커머스 트래픽 패턴, 블록체인 인프라, 특정 기술 스택 등)
- 여기어때 같은 글로벌 서비스 회사 추천 - 멘토가 해당 팀장과 네트워킹 있음
- **현실적 과제**: DevOps 분야는 완전 신입 채용이 매우 드문 편
- **멘토의 격려**: 3개월간 프로젝트를 잘 완수하면 1년차 주니어 수준의 기술 스택과 마인드셋 습득 가능

### 기술 지식 평가

- **컨테이너**: 기본 개념 이해, Docker Compose로 Grafana/Prometheus 실습 경험 있음
- **Kubernetes**: 실제 사용 경험 없음
- **네트워킹**: TCP/UDP 차이, 프로토콜 및 포트 번호 등 기본 지식 보유
- **리눅스**: 커널과 프로세스 기본 개념 이해, 시스템 콜 개념 알고 있음
- **프로세스 vs 스레드**: 기본 차이 이해하나, 메모리 관점의 깊은 이해 필요
- **개선 필요 영역**: 컨테이너/Kubernetes가 핵심 기술이므로 집중 학습 필요
