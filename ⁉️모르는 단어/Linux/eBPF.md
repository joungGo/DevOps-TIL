**eBPF**는 커널 안에서 **안전하게 사용자 정의 코드를 실행할 수 있게 해주는 기술**이다.  
원래는 네트워크 패킷 필터링(BPF)에서 시작했지만, 지금은 **관측(Observability), 보안, 네트워크, 성능 분석**까지 확장되었다.

---

# 1. 무엇을 하는 기술인가?

기존에는:

- 커널 동작을 바꾸려면
    
    - 커널 모듈 작성
        
    - 커널 재컴파일
        
    - 재부팅 필요
        

eBPF는:

> 커널을 수정하지 않고, 런타임에 안전하게 코드를 삽입해 실행

가능하게 만든다.

---

# 2. 어떻게 동작하나?

1. 사용자 공간에서 eBPF 프로그램 작성 (주로 C 기반)
    
2. 커널의 **Verifier**가 안전성 검사
    
    - 무한 루프 금지
        
    - 메모리 접근 검증
        
3. 통과하면 JIT 컴파일
    
4. 특정 커널 이벤트에 attach
    

예:

- 시스템 콜 진입 시
    
- 네트워크 패킷 수신 시
    
- 함수 호출 시
    
- 스케줄러 이벤트 시
    

---

# 3. 어디에 사용되나?

### 1) 관측 / 성능 분석

- 시스템 콜 추적
    
- 레이턴시 측정
    
- CPU 사용 분석
    
- 커널 함수 트레이싱
    

대표 도구:

- bpftrace
    
- perf
    
- BCC
    

---

### 2) 네트워크

- 패킷 필터링
    
- 로드 밸런싱
    
- DDoS 방어
    
- XDP (고속 패킷 처리)
    

---

### 3) 보안

- 비정상 시스템 콜 감지
    
- 런타임 위협 탐지
    
- 컨테이너 보안 모니터링
    

---

# 4. 왜 중요한가?

기존 방식의 문제:

- 커널 모듈은 위험
    
- 디버깅 어려움
    
- 운영 중 적용 힘듦
    

eBPF는:

- 안전성 검증됨
    
- 동적 로딩 가능
    
- 재부팅 불필요
    
- 오버헤드 낮음
    

---

# 5. 핵심 특징

- 커널 내부에서 실행
    
- 샌드박스 기반 안전 실행
    
- 이벤트 기반 hook 구조
    
- 맵(Map) 구조로 커널-유저 데이터 교환
    

---

# 6. 컨테이너 환경에서의 의미

- 네임스페이스, cgroup 단위 관찰 가능
    
- 클라우드 네이티브 환경에서 필수 기술로 자리잡음
    

---

# 한 줄 정리

eBPF는 커널을 수정하지 않고도 안전하게 커널 내부에 코드를 삽입해 관측·네트워크·보안 기능을 구현할 수 있게 해주는 고성능 확장 기술이다.
