## 정의

> 컨테이너를 생성하고 실행하고 관리하는 핵심 런타임

즉, Docker를 설치하면 실제로 동작하는 서버 프로그램이 **도커 엔진**이다.

---

## 구성 요소

도커 엔진은 크게 3가지로 구성된다.

### 1) Docker Daemon (`dockerd`)

- 실제 컨테이너 생성/실행/네트워크/볼륨 관리
    
- 백그라운드에서 항상 실행됨
    

### 2) Docker CLI

- 우리가 `docker run` 같은 명령을 입력하는 클라이언트
    

### 3) REST API

- CLI와 Daemon이 통신하는 API
    

구조적으로 보면:

```
docker CLI  →  Docker REST API  →  dockerd  →  containerd  →  runc
```

### 내부 런타임

- `containerd` : 컨테이너 생명주기 관리
    
- `runc` : 실제 리눅스 네임스페이스 + cgroup 실행
