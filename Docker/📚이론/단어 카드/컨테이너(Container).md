컨테이너(Container)는  
**애플리케이션과 그 실행에 필요한 환경을 함께 묶어서, 격리된 상태로 실행하는 기술**이다.

개발자 관점에서 말하면:

> 코드 + 라이브러리 + 런타임 + 설정 파일을 하나로 패키징해서  
> 어디서 실행하든 동일하게 동작하도록 만드는 실행 단위

---

# 왜 필요한가?

기존 방식에서는 이런 문제가 있었다.

- 내 PC: Python 3.10
    
- 서버: Python 3.8
    
- 라이브러리 버전 다름
    
- OS 환경 다름
    

이 때문에 “내 컴퓨터에서는 되는데요?” 문제가 자주 발생한다.

컨테이너를 사용하면:

- 애플리케이션 실행 환경이 완전히 격리됨
    
- 항상 동일한 환경에서 실행됨
    
- 개발, 테스트, 운영 환경이 일관됨
    

---

# VM과의 차이

|구분|VM|컨테이너|
|---|---|---|
|OS 포함 여부|게스트 OS 포함|호스트 커널 공유|
|무게|무거움|가벼움|
|실행 속도|느림|빠름|
|대표 기술|VMware|Docker|

VM은 하이퍼바이저 위에 게스트 OS를 통째로 올린다.  
컨테이너는 호스트 OS의 커널을 공유한다.

이 차이 때문에 컨테이너가 훨씬 가볍다.
