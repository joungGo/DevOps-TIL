### docker 초기화
#### 1. 실행 중이거나 중지된 모든 컨테이너 삭제

```bash
docker container rm -f $(docker container ls -aq)
```

---
#### 2. 모든 이미지 삭제

```bash
docker image rm -f $(docker image ls -q)
```

---

### docker container run ~ : 플래그(옵션) 정리
|옵션|축약|설명|예시|
|---|---|---|---|
|`--name`||컨테이너 이름 지정|`--name my-app`|
|`--detach`|`-d`|백그라운드 실행 (detached mode)|`--detach`|
|`--interactive`|`-i`|표준 입력(STDIN)을 열어둠|`-i`|
|`--tty`|`-t`|가상 터미널 할당|`-t`|
|`-it`||상호작용 터미널 모드 (`-i` + `-t`)|`-it`|
|`--publish`|`-p`|포트 매핑 (호스트:컨테이너)|`--publish 8080:80`|
|`-P`||Dockerfile에 정의된 모든 포트 자동 매핑|`-P`|
|`-v`||볼륨 마운트 (호스트:컨테이너)|`-v /host:/container`|
|`--mount`||명시적 볼륨 마운트 방식|`--mount type=bind,source=/a,target=/b`|
|`-e`||환경 변수 설정|`-e DB_HOST=localhost`|
|`--env-file`||환경 변수 파일 적용|`--env-file .env`|
|`--rm`||종료 시 자동 삭제|`--rm`|
|`--network`||네트워크 지정|`--network my-net`|
|`--restart`||재시작 정책 설정|`--restart always`|
|`--cpus`||CPU 사용 제한|`--cpus="1.5"`|
|`-m`|`--memory`|메모리 사용 제한|`-m 512m`|
|`--entrypoint`||기본 실행 명령어 덮어쓰기|`--entrypoint /bin/bash`|
|`-w`|`--workdir`|작업 디렉터리 지정|`-w /app`|

### docker에서 자주 사용하는 명령어

#### 1. 이미지(Image) 관련 명령어

| 명령어                    | 설명                  |
| ---------------------- | ------------------- |
| `docker image ls`      | 이미지 목록 조회           |
| `docker images`        | 이미지 목록 조회 (구버전 스타일) |
| `docker image pull`    | 이미지 다운로드            |
| `docker image push`    | 이미지 업로드             |
| `docker image build`   | Dockerfile로 이미지 생성  |
| `docker build`         | 이미지 생성 (축약)         |
| `docker image rm`      | 이미지 삭제              |
| `docker rmi`           | 이미지 삭제 (축약)         |
| `docker image inspect` | 이미지 상세 정보           |
| `docker image history` | 이미지 레이어 히스토리        |
| `docker image prune`   | 사용하지 않는 이미지 삭제      |
| `docker tag`           | 이미지 태그 추가           |
| `docker save`          | 이미지 파일로 저장          |
| `docker load`          | 이미지 파일 불러오기         |
| `docker import`        | tar 파일로부터 이미지 생성    |
| `docker export`        | 컨테이너를 tar로 내보내기     |
#### 2. 컨테이너(Container) 관련 명령어
|명령어|설명|
|---|---|
|`docker container run`|컨테이너 생성 + 실행|
|`docker run`|컨테이너 실행 (축약)|
|`docker container create`|컨테이너 생성만|
|`docker start`|컨테이너 시작|
|`docker stop`|컨테이너 정지|
|`docker restart`|컨테이너 재시작|
|`docker pause`|컨테이너 일시정지|
|`docker unpause`|일시정지 해제|
|`docker kill`|강제 종료|
|`docker rm`|컨테이너 삭제|
|`docker container ls`|실행 중 컨테이너 조회|
|`docker ps`|실행 중 컨테이너 조회 (축약)|
|`docker ps -a`|전체 컨테이너 조회|
|`docker logs`|로그 확인|
|`docker exec`|실행 중 컨테이너에 명령 실행|
|`docker attach`|실행 중 컨테이너에 붙기|
|`docker cp`|파일 복사 (호스트 ↔ 컨테이너)|
|`docker inspect`|상세 정보 조회|
|`docker stats`|리소스 사용량 확인|
|`docker top`|프로세스 확인|
|`docker rename`|컨테이너 이름 변경|
|`docker update`|리소스 제한 변경|
|`docker wait`|컨테이너 종료 대기|
|`docker diff`|파일 시스템 변경사항 확인|
|`docker commit`|컨테이너를 이미지로 저장|
|`docker port`|포트 매핑 확인|
#### 3. 네트워크(Network) 관련 명령어
|명령어|설명|
|---|---|
|`docker network ls`|네트워크 목록|
|`docker network create`|네트워크 생성|
|`docker network rm`|네트워크 삭제|
|`docker network inspect`|네트워크 상세 정보|
|`docker network connect`|컨테이너 네트워크 연결|
|`docker network disconnect`|네트워크 연결 해제|
|`docker network prune`|사용하지 않는 네트워크 삭제|#
