## 1️⃣ 전체 구조 한눈에 보기

이 환경은 크게 **3계층**으로 나뉩니다.

```
[인터넷]
   ↑
[호스트의 네트워크 카드]
   ↑
[VMware 가상 네트워크 (NAT)]
   ↑
[가상 머신들 (Linux / Windows)]
```

핵심 개념은 👉  
**가상 머신들은 “실제 네트워크에 직접 연결된 것처럼 보이지만”,  
실제로는 호스트 OS를 통해 간접적으로 인터넷을 사용**한다는 점입니다.

---

## 2️⃣ 진짜 컴퓨터(호스트 컴퓨터)

### ✔ 호스트 OS

- 실제 PC (Windows / macOS / Linux)
    
- **실제 네트워크 카드(NIC)** 를 가지고 있음
    
- 예시 IP:
    
    ```
    192.168.111.1
    ```
    

### ✔ 역할

- 가상 머신들의 **출입구**
    
- 외부 인터넷과 통신하는 **유일한 실제 물리 장비**
    
- 가상 머신은 **절대 인터넷과 직접 통신하지 않음**
    

---

## 3️⃣ 네트워크 카드 & 인터넷

```
가상 머신 → VMware → 호스트 OS → 네트워크 카드 → 인터넷
```

- 호스트의 네트워크 카드는:
    
    - 유선 / Wi-Fi
        
    - 회사 네트워크, 집 공유기, 공공망 등 어디든 가능
        
- 외부에서는:
    
    - **가상 머신 존재를 전혀 모름**
        
    - 모든 트래픽이 **호스트 PC에서 나온 것처럼 보임**
        

👉 이것이 **NAT(Network Address Translation)** 의 핵심

---

## 4️⃣ VMware 가상 네트워크 (가장 중요 ⭐)

그림의 가운데 큰 박스가 핵심입니다.

### 📦 VMware 프로그램 내부에 존재하는 “가상 네트워크 장비들”

#### ① 게이트웨이 / DNS 서버

```
192.168.111.2
```

역할:

- 가상 머신들의 **기본 게이트웨이**
    
- 외부로 나갈 때 반드시 거침
    
- DNS 요청도 여기로 보냄
    

👉 가상 머신 입장에서는:

```
"이 주소가 우리 네트워크의 라우터구나"
```

---

#### ② DHCP 서버

```
192.168.111.254
```

역할:

- 가상 머신에 IP를 나눠주는 서버
    
- (※ IP 할당 과정은 다음 요청 때 아주 자세히 설명 가능)
    

---

### 🔹 중요 포인트

- 이 장비들은 **실제 물리 장비가 아님**
    
- VMware가 **소프트웨어로 흉내 낸 네트워크 장비**
    
- 오직 **이 PC 안에서만 존재**
    

---

## 5️⃣ 내부 가상 네트워크 대역

```
192.168.111.0/24
```

이 의미:

- 완전히 **독립된 사설 네트워크**
    
- 외부 네트워크와 겹쳐도 상관없음
    
- 실제 회사/집 네트워크와 분리됨
    

---

## 6️⃣ 가상 머신들 (Server / Client)

### 📌 Server (A)

```
192.168.111.100
Linux
```

- 웹 서버, DB 서버, 실습용 서버 역할
    

### 📌 Server (B)

```
192.168.111.200
Linux
```

- 또 다른 서버
    
- 서버 간 통신 실습 가능
    

### 📌 Client

```
자동 IP
Linux
```

### 📌 WinClient

```
자동 IP
Windows
```

---

### 이 가상 머신들의 공통점

- 같은 네트워크에 있음
    
- 서로 **직접 통신 가능**
    
    ```
    ping 192.168.111.100
    ssh 192.168.111.200
    ```
    
- 외부로 나갈 땐:
    
    ```
    VM → 192.168.111.2 (게이트웨이) → 호스트 → 인터넷
    ```
    

---

## 7️⃣ 통신 흐름 예시 (중요⭐)

### 🌐 가상 머신이 인터넷 접속할 때

```
[Linux VM]
   ↓
[게이트웨이 192.168.111.2]
   ↓
[호스트 OS 192.168.111.1]
   ↓
[실제 공유기 / 회사망]
   ↓
[인터넷]
```

✔ 외부 서버 입장:

- 요청 보낸 주체 = **호스트 PC**
    
- 가상 머신 IP는 절대 노출 안 됨
    

---
## 8️⃣ 핵심 요약

- 이 구조는 **VMware NAT 네트워크**
    
- 가상 머신들은:
    
    - 내부 전용 네트워크에서만 존재
        
    - 외부와는 **호스트를 통해서만 통신**
        
- VMware가:
    
    - 라우터
        
    - DNS 서버
        
    - DHCP 서버  
        를 전부 **소프트웨어로 제공**
