## 1️⃣ 가상머신이란?

- **한 대의 실제 컴퓨터 안에 ‘가상의 컴퓨터’를 만드는 기술**이에요.
    
- 실제 컴퓨터에 설치된 운영체제(OS) 안에서  
    또 다른 운영체제를 **동시에 실행**할 수 있어요.

![[img.png | 650x400]]
👉 마치 **집(실제 컴퓨터)** 안에  
**방(가상머신)** 을 하나 더 만들어서  
그 방에서 또 다른 생활(운영체제)을 하는 느낌이에요.

---

## 2️⃣ 호스트 OS와 게스트 OS

- **호스트 OS (Host OS)**
    
    - 실제 PC에 **원래 설치된 운영체제**
        
    - 예: Windows 10, Windows 11, macOS, Linux
        
- **게스트 OS (Guest OS)**
    
    - 가상머신 **안에 설치된 운영체제**
        
    - 예: Windows 안에서 Ubuntu Linux 실행
        

📌 예시

```
실제 PC
 └─ Windows (호스트 OS)
     └─ 가상머신
         └─ Linux (게스트 OS)
```

---

## 3️⃣ 가상머신 소프트웨어란?

- 가상 컴퓨터를 만들어 주는 **프로그램**
    
- 대표적인 예:
    
    - VirtualBox
        
    - VMware
        
    - Hyper-V
        

이 소프트웨어가 **CPU, 메모리, 디스크를 가짜로 나눠서**  
게스트 OS가 **진짜 컴퓨터처럼** 착각하게 만들어요.

---

## 4️⃣ 멀티부팅(Multi-Booting)과의 차이

- **멀티부팅**
    
    - PC에 여러 OS를 설치
        
    - **부팅할 때 하나만 선택**
        
    - 동시에 실행 ❌
        
- **가상머신**
    
    - 호스트 OS 위에서
        
    - **여러 OS를 동시에 실행 가능** ⭕
        

📌 차이 한 줄 요약

> 멀티부팅은 “번갈아 사용”, 가상머신은 “동시에 사용”

---

## ✅ 정리

- 가상머신: 한 컴퓨터에서 여러 OS를 동시에 실행
    
- 호스트 OS: 원래 설치된 OS
    
- 게스트 OS: 가상머신 안의 OS
    
- 멀티부팅과는 개념이 다름
