# 전체 흐름 정리

```text
전원 ON
→ BIOS/UEFI
→ 부트로더 (GRUB)
→ 커널
→ init (systemd, PID 1)
→ 서비스 시작
→ 로그인
```

---

# 1. BIOS / UEFI

>통일 확장 펌웨어 인터페이스(**UEFI**) 사양은 부팅 구성과 부팅 로더를 정의한다.
 이전 시스템에서는 이 단계에서 시동 자체 시험(POST)가 완료되면 기본 I/O 시스템(BIOS)이 하드웨어를  초기화하고 부트 로더에게 제어권을 넘겨준다.

전원이 켜지면:

- 하드웨어 초기화
    
- 부팅 가능한 디스크 탐색
    
- 부트로더 실행
    

UEFI가 현대 시스템의 표준 방식이다.

---

# 2. 부트로더 (Bootloader)

>부트 로더의 목표는 커널을 부트스트랩하는 것이다. 부트 로더의 옵션은 다양하며, 현재, 이전 버전 모두 사용할 수 있다.

대표적으로:

- GRUB
    

역할:

- 커널 이미지 선택
    
- 커널을 메모리에 적재
    
- initramfs 로드
    
- 커널에 제어권 전달
    

---

# 3. 리눅스 커널

>커널은 일반적으로 압축된 형태로 /boot 디렉토리에 위치해 있다. 따라서 첫 번째 단계는 커널을 추출해 메인 메모리에 로드하는 것이다. 하위 시스템, 파일시스템, 드라이버를 초기화하고 나며 커커널을 init 시스템에 제어권을 넘기고 이로써 부팅 프로세스는 종료된다.

커널이 실행되면:

1. 메모리 초기화
    
2. CPU/디바이스 초기화
    
3. 드라이버 로드
    
4. 루트 파일 시스템 마운트
    
5. 첫 사용자 공간 프로세스 실행
    

그리고 PID 1 프로세스를 시작한다.

---

# 4. init 프로세스 (PID 1)

>init 시스템은 시스템 전반에 걸쳐 데몬을 실행할 책임이 있다. 이 init 프로세스는 프로세스 계층 구조의 루트이며 프로세스 ID(PID)는 1을 가진다. 즉 PID 1 프로세스는 시스템 전원을 끌 때까지 실행된다. 다른 데몬 실행을 담당하는 것 외에도 PID 1 프로세스는 고아 프로세스를 처리한다.

과거:

- SysV init
    

현재 대부분:

- systemd
    

역할:

- 서비스 시작
    
- 네트워크 설정
    
- 로그인 서비스 실행
    
- 데몬 관리
    

즉, 사용자 공간의 모든 프로세스의 부모 역할을 한다.

---

# 5. 로그인 및 사용자 세션

- getty 실행
    
- 로그인 인증
    
- 셸 실행 (bash 등)
    

이후 일반 사용자 환경으로 진입한다.

---

# 한 줄 정리

리눅스는 BIOS/UEFI가 부트로더를 실행하고, 부트로더가 커널을 로드하며, 커널은 PID 1(init/systemd)을 실행해 사용자 공간과 시스템 서비스를 시작한다.
