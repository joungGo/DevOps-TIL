## SMT (Simultaneous Multi-Threading)

하나의 **물리 코어**가  
여러 개의 **논리 스레드(Logical Thread)** 를 동시에 실행하는 기술

대표적인 예: Intel의 Hyper-Threading

---

## 왜 필요한가?

CPU 내부에는 다음과 같은 자원이 있음:

- ALU (연산 유닛)
    
- FPU
    
- 로드/스토어 유닛
    
- 파이프라인 슬롯
    

하나의 스레드만 실행하면  
이 자원들이 항상 100% 사용되지 않음.

→ 남는 실행 자원을 다른 스레드가 활용하도록 만든 것이 SMT

---

## 기본 구조

### SMT 없음

```
1 코어 → 1 스레드 실행
```

### SMT 있음

```
1 물리 코어
   ├─ 논리 스레드 1
   └─ 논리 스레드 2
```

운영체제는 이를 2개의 CPU처럼 인식함.

---

## 동작 원리

- 각 스레드는 **독립적인 레지스터 집합**을 가짐
    
- 하지만 다음은 공유함:
    
    - 실행 유닛
        
    - 캐시
        
    - 메모리 대역폭
        

CPU는 한 사이클 안에서  
두 스레드의 명령을 동시에 발행하거나  
빈 실행 슬롯에 다른 스레드 명령을 채움.

---

## 장점

1. CPU 자원 활용률 증가
    
2. 대기 시간 감소 (메모리 접근 지연 시 다른 스레드 실행)
    
3. 처리량(Throughput) 향상
    

---

## 단점

1. 실행 유닛을 공유하므로 완전한 2배 성능은 아님
    
2. 캐시 경쟁 발생 가능
    
3. 보안 취약점(Side-channel) 이슈 가능
    

---

## 멀티코어와 차이

멀티코어:

```
2 코어 → 물리적으로 2개
```

SMT:

```
1 코어 → 논리적으로 2개
```

멀티코어는 물리 자원이 증가  
SMT는 기존 자원을 더 효율적으로 사용

---

## 한 줄 정리

SMT는 하나의 물리 코어에서 여러 스레드를 동시에 실행하여  
CPU 내부 유휴 자원을 최대한 활용하는 기술이다.
