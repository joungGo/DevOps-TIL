## 1. 파일 시스템 생성

> 저장 공간(파티션/볼륨)에 파일을 저장할 구조를 만드는 작업

대상:

- 파티션 (`/dev/sda1`)
    
- 논리 볼륨 (`/dev/mapper/vg-lv`)
    

대표 명령:

```bash
mkfs.ext4 /dev/sda1
```

이 과정에서 생성되는 것:

- 슈퍼블록
    
- 아이노드 테이블
    
- 데이터 블록 영역
    
- 저널(파일 시스템 종류에 따라)
    

즉,

> “비어 있는 저장 공간에 파일 시스템 구조를 만드는 작업”

주의: 기존 데이터는 삭제됨.

---

## 2. 파일 시스템 마운트

> 생성된 파일 시스템을 디렉토리 경로에 연결하는 작업

대표 명령:

```bash
mount /dev/sda1 /mnt
```

의미:

```text
/dev/sda1의 파일 시스템 → /mnt 디렉토리에 연결
```

이제 `/mnt` 아래에서 파일 접근 가능.

마운트 전:

- 디스크는 존재하지만 접근 불가
    

마운트 후:

- 디렉토리를 통해 접근 가능
    

---

# 흐름 정리

```text
1. 파티션 생성
2. mkfs → 파일 시스템 생성
3. mount → 디렉토리에 연결
```

---

# 한 줄 정리

파일 시스템 생성은 저장 장치에 파일 구조를 만드는 것이고, 마운트는 그 파일 시스템을 특정 디렉토리에 연결해 사용할 수 있게 하는 과정이다.
