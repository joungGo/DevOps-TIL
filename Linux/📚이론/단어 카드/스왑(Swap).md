물리 메모리가 부족하면 즉시 OOM이 발생한다. 
OOM이 즉시 발생하는 것을 방지하기 위해 **스왑**을 사용한다.

사용중인 메모리 영역의 일부를 저장 장치로 옮겨 메모리에 빈 공간을 만든다. 이때, 데이터를 옮긴 저장 장치의 영역을 **스왑 영역** 이라고 한다. 

물리 메모리 내부에서 한동안 사용되지 않을 거라고 커널이 판단한 데이터를 스왑 영역으로 옮기게 되는데 이 처리를 **페이지 아웃** 또는 **스왑 아웃** 이라고 한다.

이후, 스왑 영역으로 옮긴 데이터에 대한 페이지에 재접근하면 해당 데이터를 다시 물리 메모리로 읽어오게 되는데 이런 작업을 **페이지 인** 또는 **스왑 인** 이라고 한다.
