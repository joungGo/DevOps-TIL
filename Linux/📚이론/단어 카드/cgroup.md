cgroup은

> 프로세스 그룹 단위로 CPU, 메모리, I/O 같은 시스템 자원을 제한하고 추적하는 리눅스 커널 기능

이다.

네임스페이스가 **보이는 범위를 격리**한다면,  
cgroup은 **사용할 수 있는 자원의 양을 제한**한다.

---

# 1. 왜 필요한가

기본 리눅스에서는:

- 모든 프로세스가 CPU를 경쟁
    
- 메모리 과다 사용 가능
    
- I/O 독점 가능
    

즉, 한 프로세스가 시스템을 망가뜨릴 수 있다.

cgroup은 이를 막기 위해 등장했다.

---

# 2. 핵심 개념

```text
프로세스 → 그룹으로 묶음 → 그룹 단위로 자원 제한
```

예:

- 컨테이너 A → CPU 1코어 제한
    
- 컨테이너 B → 메모리 512MB 제한
    

---

# 3. 제한 가능한 자원

## 1) CPU

- 사용 비율 제한
    
- 코어 할당
    

## 2) Memory

- 최대 메모리 제한
    
- OOM 발생 시 강제 종료
    

## 3) Block I/O

- 디스크 읽기/쓰기 속도 제한
    

## 4) PIDs

- 생성 가능한 프로세스 수 제한
    

---

# 4. 네임스페이스와의 차이

|구분|namespace|cgroup|
|---|---|---|
|목적|격리|자원 제한|
|대상|보이는 범위|사용 가능한 양|
|예|PID, 네트워크 분리|CPU 50% 제한|

---

# 5. 컨테이너에서의 역할

컨테이너는 단순히 격리된 프로세스 집합이 아니라:

```text
namespace → 자원 격리
cgroup → 자원 제한
```

이 조합으로 구성된다.

예:

- 10개 컨테이너가 동시에 실행되더라도
    
- 각 컨테이너는 정해진 자원만 사용
    

---

# 6. cgroup v1 vs v2

- v1 → 컨트롤러별 독립 구조
    
- v2 → 통합 계층 구조 (현대 리눅스 기본)
    

v2는 더 일관된 리소스 관리 제공.

---

# 한 줄 정리

cgroup은 프로세스를 그룹으로 묶어 CPU, 메모리, I/O 등의 자원을 제한하고 추적하는 리눅스 커널의 리소스 제어 메커니즘이다.
