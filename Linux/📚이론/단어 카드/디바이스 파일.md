# 1. 디바이스 파일(Device File)

리눅스에서는 **장치도 파일로 추상화**한다.  
위치는 보통 `/dev` 디렉터리 아래에 존재한다.

```
/dev/sda
/dev/tty
/dev/null
```

---

# 2. 디바이스 파일 종류

## 1) 캐릭터 장치 (Character Device)

읽고 쓰기는 가능하지만, 장치 내부에서 접근할 장소를 변경하는 **탐색** 조작이 **불가능**하다.

- 데이터를 **바이트 단위(스트림)**로 처리
    
- 버퍼링 없이 순차 접근
    
- 랜덤 접근 불가
    

### 예

- 키보드 `/dev/tty`, 마우스, 단말
    
- 시리얼 포트
    
- `/dev/null`
    

### 특징

- read/write 즉시 처리
    
- seek 거의 의미 없음
    

---

## 2) 블록 장치 (Block Device)

읽고 쓰기는 가능하며, 장치 내부에서 접근할 장소를 변경하는 **탐색** 조작도 **가능**하다.

- 데이터를 **블록 단위(보통 512B, 4KB)**로 처리
    
- 랜덤 접근 가능
    
- 파일 시스템이 올라갈 수 있음
    

### 예

- 하드디스크 `/dev/sda`
    
- SSD
    
- USB
    

### 특징

- 캐시 사용
    
- seek 가능
    

---

# 3. 메이저 번호 / 마이너 번호

`ls -l /dev/sda` 같은 명령어를 보면:

```
brw-rw---- 1 root disk 8, 0 ...
```

여기서 `8, 0` 이  
→ **메이저 번호, 마이너 번호**

---

## 1) 메이저 번호 (Major Number)

- 어떤 **디바이스 드라이버**인지 식별
    
- 커널이 어떤 드라이버를 사용할지 결정
    

즉,  
"이 장치는 어떤 종류의 장치인가?"

예:

- 8 → SCSI 디스크 드라이버
    

---

## 2) 마이너 번호 (Minor Number)

- 해당 드라이버 안에서 **구체적인 장치 구분**
    
- 같은 종류 장치들 중에서 번호 구분
    

즉,  
"그 드라이버가 관리하는 장치 중 몇 번째인가?"

예:

- 8,0 → sda
    
- 8,1 → sda1 (파티션)
    

---

# 4. 중요한 개념

> 메이저 + 마이너 번호의 조합이 같으면 같은 장치를 의미한다.

왜냐하면,

커널은 내부적으로 이렇게 매핑한다:

```
(major, minor) → 디바이스 드라이버 → 실제 하드웨어
```

따라서 두 디바이스 파일이:

- 메이저 동일
    
- 마이너 동일
    

이면  
→ 완전히 같은 장치를 가리킨다.  
(파일 이름이 달라도 동일 장치 가능)

---

# 5. 전체 구조 요약

```
프로세스
   ↓
디바이스 파일 (/dev/xxx)
   ↓ (major, minor)
커널
   ↓
디바이스 드라이버 (major로 선택)
   ↓
실제 장치 (minor로 구분)
```
