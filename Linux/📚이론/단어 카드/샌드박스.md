샌드박스는

> 프로그램을 제한된 환경 안에서 실행해 시스템 전체에 영향을 주지 못하게 하는 격리 기술

이다.

이름 그대로 “모래상자 안에서만 놀게 하는 것”에 비유된다.

---

# 1. 왜 필요한가

어떤 프로그램이:

- 악성 코드일 수도 있고
    
- 취약점이 있을 수도 있고
    
- 외부 입력을 많이 받을 수도 있다
    

이때 프로그램이 시스템 전체에 접근하면 위험하다.

따라서:

```text
허용된 자원만 접근 가능
그 외는 차단
```

이라는 환경을 만든다.

---

# 2. 무엇을 제한하나

샌드박스는 보통 다음을 제한한다.

- 파일 시스템 접근
    
- 네트워크 접근
    
- 다른 프로세스 접근
    
- 시스템 콜
    
- 디바이스 접근
    

즉, “권한과 자원 범위”를 줄인다.

---

# 3. 리눅스에서의 구현 방식

리눅스에서는 여러 기능을 조합해 샌드박스를 만든다.

- namespace → 자원 격리
    
- cgroup → 리소스 제한
    
- seccomp → 시스템 콜 제한
    
- capability → 특권 기능 제한
    
- SELinux/AppArmor → 접근 제어
    

컨테이너도 일종의 샌드박스다.

---

# 4. 실제 예시

## 브라우저

웹 브라우저는 탭마다 격리된 프로세스를 둔다.  
악성 웹페이지가 OS 전체를 건드리지 못하게 하기 위함이다.

## Flatpak

Flatpak은 앱을 샌드박스 안에서 실행한다.

예:

- 홈 디렉토리 전체 접근 불가
    
- 사용자가 허용한 디렉토리만 접근 가능
    

---

# 5. 샌드박스와 가상 머신 차이

|구분|샌드박스|가상 머신|
|---|---|---|
|격리 수준|프로세스 수준|OS 수준|
|커널|공유|분리|
|무게|가벼움|무거움|

샌드박스는 제한된 권한의 실행 환경이고,  
가상 머신은 완전히 분리된 운영체제 환경이다.

---

# 한 줄 정리

샌드박스는 프로그램을 제한된 권한과 자원 범위 안에서 실행시켜 시스템 전체에 영향을 주지 못하도록 격리하는 보안 기술이다.
