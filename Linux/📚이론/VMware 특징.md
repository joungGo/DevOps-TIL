## ① 한 대의 컴퓨터로 실무와 거의 같은 환경 구성 가능

- 물리 PC 1대 위에 **여러 대의 가상 컴퓨터**를 만들 수 있음
    
- 서버, 클라이언트, DB 서버 등을 **네트워크로 연결된 것처럼** 구성 가능
    
- 실제 회사 서버 환경을 **연습/테스트용으로 그대로 재현**할 수 있음
    

👉 실습·학습·테스트에 매우 유리

---

## ② 스냅샷(Snapshot) 기능 사용 가능

- **운영체제의 특정 시점 상태를 저장**
    
- 문제가 생기면 **언제든지 그 시점으로 되돌릴 수 있음**
    

### 예시

1. 리눅스 설치 완료 → 스냅샷
    
2. 여러 설정/실험 진행
    
3. 오류 발생 → 스냅샷으로 복구
    

👉 OS 재설치 필요 없음  
👉 실습 중 실수해도 안전

---

## ③ 하드웨어를 마음대로 추가·변경하며 테스트 가능

- 실제로 하드웨어를 사지 않아도:
    
    - 하드디스크 여러 개 추가
        
    - 메모리 용량 변경
        
    - CPU 개수 변경
        
- **버튼 몇 번으로 실험 가능**
    

👉 서버 구성 테스트  
👉 장애 상황 연습에 좋음

---

## ④ Suspend(일시 정지) 기능

- 현재 가상머신 상태를 **그대로 저장**
    
- 다음에 실행하면 **중단했던 화면부터 바로 이어서 사용**
    

### 전원 끄기 vs Suspend

|구분|전원 끄기|Suspend|
|---|---|---|
|다음 실행|처음부터 부팅|즉시 복귀|
|속도|느림|매우 빠름|

👉 작업 중단/재개가 편리
