아래는 **tmux를 완전 처음부터 배우는 사람**을 기준으로 한 단계별 학습 시나리오입니다.

전제:

- 터미널은 열 수 있다
    
- 리눅스/WSL/macOS 환경에서 작업 중이다
    
- tmux는 설치되어 있다 (`tmux -V`로 확인)
    

---

# 0단계 — tmux가 무엇인지부터 이해하기

## 1. 터미널의 한계

일반 터미널에서:

- SSH 접속 후 작업
    
- 네트워크가 끊기면 실행 중이던 프로그램 종료
    
- 한 화면에서 여러 작업을 동시에 관리하기 어려움
    

## 2. tmux의 역할

tmux는 **터미널 안에서 또 다른 터미널 환경을 만드는 도구**입니다.

기능:

- 세션 유지 (연결이 끊겨도 작업 계속)
    
- 화면 분할
    
- 여러 작업을 하나의 논리적 작업 공간으로 관리
    

구조:

```
Session
 ├─ Window
 │   ├─ Pane
```

- Session = 프로젝트 단위
    
- Window = 작업 단위
    
- Pane = 화면 분할
    

이 구조를 머리에 먼저 넣는 것이 중요합니다.

# 1단계 — 세션(Session) 이해

## 목표

“tmux는 세션이 핵심이다”를 이해한다.

## 1. 세션 만들기

```bash
tmux new -s study
```

이 순간:

- 새로운 세션 생성
    
- 터미널이 tmux 내부로 진입
    

화면 하단에 상태바가 보이면 성공입니다.

---

## 2. 세션 분리(detach)

키 입력:

```
Ctrl + b → d
```

의미:

- tmux는 계속 실행
    
- 나는 빠져나옴
    

---

## 3. 세션 목록 확인

```bash
tmux ls
```

---

## 4. 다시 접속

```bash
tmux attach -t study
```

### 이 단계에서 이해해야 할 핵심

- 세션은 살아있는 작업 공간
    
- detach는 종료가 아니다
    
- SSH 환경에서 반드시 필요
    

---

# 2단계 — Window 이해

## 개념

Window는 **세션 안의 작업 탭**입니다.

브라우저 탭과 비슷합니다.

---

## 1. 새 Window 만들기

```
Ctrl + b → c
```

새 터미널 탭이 생깁니다.

---

## 2. Window 이동

```
Ctrl + b → n   (다음)
Ctrl + b → p   (이전)
Ctrl + b → w   (목록)
```

---

## 3. Window 이름 변경

```
Ctrl + b → ,
```

### 실습 시나리오

Window 1: server  
Window 2: logs  
Window 3: git

이 단계 목표:

- “한 세션 = 하나의 프로젝트”
    
- “한 window = 하나의 역할”
    

---

# 3단계 — Pane 이해 (화면 분할)

## 개념

Pane은 하나의 window 안을 나눈 것입니다.

---

## 1. 수직 분할

```
Ctrl + b → %
```

---

## 2. 수평 분할

```
Ctrl + b → "
```

---

## 3. Pane 이동

```
Ctrl + b → 방향키
```

---

## 4. 크기 조절

```
Ctrl + b → Ctrl + 방향키
```

---

## 실습 시나리오

왼쪽: 코드  
오른쪽 위: 서버 실행  
오른쪽 아래: 로그

이 단계 목표:

- 마우스 없이 화면 구성
    
- 동시에 여러 작업 관찰
    

---

# 4단계 — 복사 모드

## 왜 필요한가

서버 로그를 복사해야 하는 상황이 자주 발생합니다.

---

## 1. 복사 모드 진입

```
Ctrl + b → [
```

---

## 2. 검색

```
/에러텍스트
```

---

## 3. 선택 시작

```
Space
```

---

## 4. 복사 완료

```
Enter
```

---

## 5. 붙여넣기

```
Ctrl + b → ]
```

이 단계 목표:

- 마우스 없이 로그 분석 가능

# 5단계 — 실전 프로젝트 구성

## 시나리오: 웹 개발

세션 생성:

```bash
tmux new -s api-project
```

Window 구성:

1. server
    
2. test
    
3. db
    
4. git
    

Pane 분할로:

- 서버 실행
    
- 로그 확인
    
- 테스트 반복
    

핵심 습관:

SSH 접속 → 바로 tmux attach

---

# 6단계 — 서버 운영 패턴

## 상황

- 프로덕션 서버 접속
    
- 배포 중 연결 끊김 방지
    

절차:

```bash
ssh server
tmux attach || tmux new -s prod
```

이제 항상 안전한 환경에서 작업하게 됩니다.

# 7단계 — 설정 파일 이해

파일:

```
~/.tmux.conf
```

기본 추천 설정:

```
set -g mouse on
set -g history-limit 100000
set -g base-index 1
setw -g pane-base-index 1
```

적용:

```bash
tmux source-file ~/.tmux.conf
```
