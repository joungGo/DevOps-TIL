| 명령어        | 핵심 설명                                             |
| ---------- | ------------------------------------------------- |
| `&` (앰퍼샌드) | 명령어를 **백그라운드에서 실행**                               |
| `\` (백슬래시) | **특수문자 이스케이프** 또는 **줄바꿈 연결**                      |
| `\|` (파이프) | 앞 명령어의 **출력을 뒤 명령어의 입력으로 전달**                     |
| `set`      | **셸 변수 및 옵션 설정/조회**                               |
| `unset`    | **셸 변수 또는 함수 제거**                                 |
| `export`   | 변수를 **환경 변수로 설정**하여 자식 프로세스에 전달                   |
| `$`        | **변수 값 참조** (예: `$HOME`)                          |
| `env`      | 현재 **환경 변수 목록 출력**                                |
| `grep`     | 텍스트에서 **패턴 검색**                                   |
| `exit`     | 현재 **셸 또는 프로그램 종료**                               |
| `Ctrl + Z` | 실행 중인 프로세스를 **일시 정지(suspend)** 하고 백그라운드 대기 상태로 전환 |
| `nohup`    | 터미널 종료 후에도 **프로세스가 종료되지 않도록 실행** (HUP 신호 무시)      |
