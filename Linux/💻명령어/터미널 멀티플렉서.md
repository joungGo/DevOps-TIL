# 1. tmux

현재 가장 널리 사용되는 멀티플렉서입니다. 서버 작업, SSH 세션 유지, DevOps 환경에서 표준처럼 쓰입니다.

## 1-1. 세션 관리

| 기능            | 명령어                              |
| ------------- | -------------------------------- |
| 새 세션 시작       | `tmux`                           |
| 이름 지정 세션 생성   | `tmux new -s mysession`          |
| 세션 목록         | `tmux ls`                        |
| 세션 접속         | `tmux attach -t mysession`       |
| 세션 분리(detach) | `Ctrl + b` → `d`                 |
| 세션 종료         | `tmux kill-session -t mysession` |

---

## 1-2. 창(Window) 관리

|기능|단축키|
|---|---|
|새 창 생성|`Ctrl + b` → `c`|
|다음 창|`Ctrl + b` → `n`|
|이전 창|`Ctrl + b` → `p`|
|창 목록|`Ctrl + b` → `w`|
|창 이름 변경|`Ctrl + b` → `,`|
|창 닫기|`exit`|

---

## 1-3. 패널(Pane) 분할

|기능|단축키|
|---|---|
|수직 분할|`Ctrl + b` → `%`|
|수평 분할|`Ctrl + b` → `"`|
|패널 이동|`Ctrl + b` → 방향키|
|패널 닫기|`exit`|
|패널 크기 조절|`Ctrl + b` → `Ctrl + 방향키`|
|패널 번호 표시|`Ctrl + b` → `q`|

---

## 1-4. 기타 유용한 기능

|기능|명령|
|---|---|
|복사 모드|`Ctrl + b` → `[`|
|설정 리로드|`tmux source-file ~/.tmux.conf`|
|현재 세션 이름 확인|`tmux display-message '#S'`|

---

# 2. GNU Screen

tmux 이전 세대 멀티플렉서입니다. 일부 레거시 서버에서 여전히 사용됩니다.

## 2-1. 세션 관리

|기능|명령어|
|---|---|
|시작|`screen`|
|이름 지정|`screen -S mysession`|
|세션 목록|`screen -ls`|
|재접속|`screen -r mysession`|
|분리(detach)|`Ctrl + a` → `d`|
|세션 종료|`exit`|

---

## 2-2. 창 관리

|기능|단축키|
|---|---|
|새 창|`Ctrl + a` → `c`|
|다음 창|`Ctrl + a` → `n`|
|이전 창|`Ctrl + a` → `p`|
|창 목록|`Ctrl + a` → `"`|
|창 종료|`exit`|

---

# 3. Zellij

최근 등장한 Rust 기반 모던 멀티플렉서입니다. 설정 없이 바로 쓰기 좋습니다.

## 기본 사용

|기능|명령어|
|---|---|
|실행|`zellij`|
|세션 목록|`zellij list-sessions`|
|세션 접속|`zellij attach mysession`|
|세션 종료|`zellij kill-session mysession`|

기본 단축키는 `Ctrl + p` 기반(기본 모드 시스템 사용)

---

# 4. 멀티플렉서 비교

|항목|tmux|Screen|Zellij|
|---|---|---|---|
|현재 표준성|매우 높음|낮음|증가 중|
|설정 자유도|매우 높음|보통|중간|
|플러그인|풍부|거의 없음|점점 증가|
|러닝커브|중간|낮음|낮음|
|추천도|가장 추천|레거시|개인 개발자|
